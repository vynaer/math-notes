001 · 数论 / 分析 十进制正规数

一个实数的小数无限展开中，任意 k 位数字串出现的极限概率均等，即所有 10k 种等长串以相同频率出现，称该数为十进制正规数。

严格定义：设实数 x ∈ (0, 1) 的十进制小数展开为 x = 0.a1a2a3…an…，对任意长度 k ≥ 1，任意长度为 k 的数字串 s ∈ {0, …, 9}k，记 Ns(n) 为前 n 位中 s 出现的次数。若

limn→∞ Ns(n)n = 110k

对一切 s 成立，则称 x 为十进制正规数。同理可定义 b 进制正规数。

正规数的构造性结果

科普兰-厄尔多斯常数

全体素数拼接：0.2357111317192329… 是十进制正规数。任意进制同理。

达文波特-厄尔多斯多项式族

任取非常数整系数多项式 f(n)（f(n)→+∞），则 0.f(1)f(2)f(3)… 是正规数。如 f(n)=n, n2, 2n+1。

Stoneham 常数族

αb,c = ∞∑k=1 1ck · bck

在 b 进制下正规，但在 bc 进制下不正规——正规性是依赖于进制的性质。

几乎所有实数都是正规数（测度为 1），但具体证明某个常见常数（如 π、√2、e）是正规数却极其困难——至今无人能证。几乎所有数都满足，但你一个也举不出来。能构造出的正规数不多，大多"人为拼出来"。Stoneham 常数揭示了进制依赖性：一个数可以在二进制下正规，在六进制下却不正规。

波莱尔定理与"几乎所有"

1909 年，埃米尔·波莱尔证明：几乎所有实数在任何进制下都是正规数。这里"几乎所有"是勒贝格测度意义下的——不正规的实数构成一个零测集。证明思路用了强大数定律：把十进制展开看成独立同分布的随机变量序列，每位数字取 0~9 的概率均等，由强大数定律，频率几乎必然收敛到 1/10。

这个定理的反直觉之处在于：它保证了正规数"遍地都是"，但我们却连一个自然出现的常数（π、e、√2）的正规性都证明不了。这是"存在性证明 vs 构造性证明"差距的经典案例。

外尔等分布准则

正规性与等分布密切相关。赫尔曼·外尔 1916 年证明：序列 {an} 在 [0,1) 上等分布 ⟺ 对任意非零整数 k，limN→∞ 1N N∑n=1 e2πik·an = 0。

对正规数 x，序列 {10nx mod 1} 在 [0,1) 上等分布。这给出了检验正规性的解析工具：计算指数和的极限。例如 {nα mod 1} 对无理数 α 等分布（外尔定理），但这只说明 x = 0.α2α3α… 形式的数在某种意义下"均匀"，不等于十进制正规。

进制依赖性：Stoneham 常数的震撼

Stoneham 常数 αb,c 在 b 进制下正规，但在 bc 进制下不正规。这意味着正规性不是数的内禀性质，而是依赖于进制的。一个数可以在二进制下"完全随机"，在六进制下却有规律。

这打破了"正规数 = 随机数"的直觉。真正"绝对正规"（在所有进制下都正规）的数几乎所有实数都是，但构造一个具体的绝对正规数非常困难。

已知与未知
  1. 已知正规：科普兰-厄尔多斯常数（素数拼接）、达文波特-厄尔多斯多项式族、Stoneham 常数族（特定进制下）
  2. 未知（猜测正规但未证明）：π, e, √2, ln 2, ζ(3)……几乎所有你叫得出名字的常数
  3. 已知不正规：有理数（有限循环小数）、Liouville 数 ∑10−n!（在十进制下有大量 0）
  4. 开放问题：π 是否十进制正规？这是数论中最著名的开放问题之一，数值计算到万亿位仍未发现异常，但证明遥遥无期
002 · 数论 / 组合 斐波那契进制与泽肯多夫定理

斐波那契进制（泽肯多夫表示）

以斐波那契数列为位权的记数系统。约定 F1 = 1，F2 = 2，F3 = 3，F4 = 5，F5 = 8…… 任意正整数 N 可写作：

N = ∑k dk Fk，其中 dk ∈ {0, 1}

且不允许出现连续的 1。例如 10101Fib = F5 + F3 + F1 = 8 + 3 + 1 = 12。进位规则：011Fib → 100Fib。

泽肯多夫定理

定理：任一正整数可唯一表示为若干个不相邻的斐波那契数之和。

存在性（归纳法）：取满足 Fm ≤ n < Fm+1 的最大下标 m，记 r = n − Fm。则 r < Fm−1，由归纳假设 r 有合法表示且最大项 < Fm−1，不与 Fm 相邻。

唯一性：设两种表示最大下标不同，不含 Fm 的一边最大值为 Fm−1 + Fm−3 + … < Fm（隔项和严格小于下一项），矛盾。

二进制的唯一性几乎显然（每位取 0 或 1），但斐波那契进制加上"不相邻"约束后唯一性反而需要证明——证明本身揭示了斐波那契数列"隔项和小于下一项"这个优雅性质。长度为 n 的 0/1 串中不出现相邻 1 的方案数恰好是斐波那契数，这正是该进制的计数基础。

为什么"不相邻"是关键约束

如果允许相邻的 1，同一个数会有多种表示。例如 4 = 101Fib（F3+F1=3+1）也 = 11Fib（F2+F1=2+2）。加上"不相邻"约束后，每种表示唯一。这类似于二进制中每位只能 0 或 1，而斐波那契进制中"相邻位不能同时为 1"。

泽肯多夫表示的算法

给定正整数 N，求其泽肯多夫表示：

  1. 找到最大的 Fm ≤ N
  2. 记下 Fm，令 N = N − Fm
  3. 对新的 N 重复，直到 N = 0

由于 Fm − Fm−1 = Fm−2 < Fm−1，每次减去 Fm 后余数 < Fm−1，所以下一个选的斐波那契数至多是 Fm−2，自动保证"不相邻"。

示例：N = 100。最大 Fm ≤ 100 是 F10 = 89。100−89 = 11。最大 F ≤ 11 是 F5 = 8。11−8 = 3 = F3。所以 100 = 89+8+3 = F10+F5+F3 = 100010100Fib。

与黄金比例的联系

斐波那契数列的增长由黄金比例 φ = (1+√5)/2 ≈ 1.618 控制：Fn ≈ φn/√5。因此泽肯多夫表示的位数约为 logφ N ≈ 1.44 log2 N，比二进制多约 44% 的位数。

这看似不经济，但"不相邻"约束带来了特殊优势——在数据压缩中，斐波那契编码（Fibonacci coding）利用这一性质实现了无前缀码：任何码字都不以"11"结尾（除了终止符），因此可以在比特流中唯一分割。

斐波那契编码（数据压缩应用）

泽肯多夫表示在编码理论中有实际应用。将正整数 n 的泽肯多夫表示末尾加一个"1"作为终止符，就得到斐波那契码。例如：

  • 1 = F1 → 11
  • 2 = F2 → 011
  • 3 = F3 → 0011
  • 4 = F3+F1 → 1011
  • 5 = F4 → 00011

由于泽肯多夫表示中没有相邻的 1，末尾加"1"后唯一的"11"出现在结尾，解码器扫描到"11"就知道一个码字结束了。这种编码对小整数高效，广泛用于通用压缩算法。

三种进制对比
  1. 二进制：每位 0/1，唯一性显然，位数 ⌊log₂n⌋+1
  2. 斐波那契进制：每位 0/1 且不相邻，唯一性需证明，位数约 1.44·log₂n，无前缀编码优势
  3. 十进制：每位 0~9，唯一性显然，位数约 log₁₀n
003 · 分析 / 复变 朗伯 W 函数

朗伯 W 函数 W(z) 是 f(w) = w·ew 的反函数：x·ex = t ⟺ x = W(t)。分为两支：

  • 主分支 W0(z)：定义域 z ≥ −1e ≈ −0.36
  • 负分支 W₋1(z)：定义域 −1e ≤ z < 0

两支在 z = −1e 处汇合：W0(−1e) = W₋1(−1e) = −1。

基本性质

  • W(z) ~ ln z − ln ln z，当 z → +∞
  • 导数：W'(z) = W(z)z(1 + W(z))，W'(0) = 1
  • 泰勒展开：W0(z) = ∞∑n=1 (−n)n−1n! zn，|z| < 1e

Ω 常数

Ω = W0(1) ≈ 0.567，满足 e−Ω = Ω。Ω 是超越数。其他数值：W0(2) ≈ 0.853，W0(3) ≈ 1.05。

初次遇到 x·ex = t 或 x + ln x = t 时，W 函数就像"开方"——它不是初等函数，但一旦认识了它，一大类超越方程就有了"闭式解"。

用 W 函数解方程的典型套路

核心技巧：把方程整理成 "某个式子 · e某个式子 = 常数" 的形式，然后两边取 W。

例 1：x·2x = 1。两边除以 2x 的底数相关项：x·ex ln 2 = 1。令 u = x ln 2，则 x = u/ln 2，代入得 (u/ln 2)·eu = 1，即 u·eu = ln 2。故 u = W(ln 2)，x = W(ln 2)/ln 2。

例 2：x + ln x = 5。两边取指数：x·ex = e5，故 x = W(e5)。

例 3：xx = 100。取对数：x ln x = ln 100。令 u = ln x，则 x = eu，代入得 eu·u = ln 100，即 u·eu = ln 100。故 u = W(ln 100)，x = eW(ln 100)。又由 W(z)·eW(z) = z 得 eW(z) = z/W(z)，所以 x = ln 100 / W(ln 100)。

W 函数与树计数（Cayley 公式）

W 函数的泰勒展开系数与有根标号树的计数密切相关。Cayley 公式：n 个顶点的有根标号树有 nn−1 棵。W 函数的展开：

W0(z) = ∞∑n=1 (−n)n−1n! zn = z − z2 + 32z3 − 83z4 + …

系数 (−n)n−1/n! 的绝对值正是 nn−1/n!，即 n 个顶点有根树数除以 n!。这是组合数学中"生成函数 ↔ 计数"的漂亮联系。

应用场景

  • 延迟微分方程：y'(t) = a·y(t−τ) 的特征方程 λ = a·e−λτ，解为 λ = W(aτ)/τ
  • 种群增长：逻辑斯蒂映射的不动点、SIR 模型的最终规模
  • 统计力学：玻色-爱因斯坦分布的反函数
  • 电路：二极管 I-V 特性的反解
  • 算法分析：随机快速排序的某些渐近分析中出现

数值计算

W 函数没有初等表达式，数值计算常用迭代法。由 W(z)eW(z) = z，取对数得 W = ln z − ln W，可用不动点迭代：Wn+1 = ln z − ln Wn。对大 z，初值取 ln z − ln ln z 收敛很快。更高效的方法是用 Halley 迭代（三阶收敛）。

在分支点 z = −1/e 附近，W 有平方根型奇点：W(z) ≈ −1 + √(2(ez+1))，这解释了两支 W0 和 W₋₁ 在此汇合。

W 函数速查
  1. 定义：W(z)eW(z) = z
  2. 定义域：W0 在 [−1/e, ∞)，W₋₁ 在 [−1/e, 0)
  3. 特殊值：W(0)=0, W(1/2)≈0.352, W(1)=Ω≈0.567, W(e)=1, W(2e²)=2
  4. 渐近：W(z) ~ ln z − ln ln z（z→∞）
  5. 恒等式：W(z·ez) = z；eW(z) = z/W(z)
004 · 分析 / 超运算 迭代幂运算（Tetration）与幂塔导数

加法是重复计数，乘法是重复加法，幂运算是重复乘法——那么"重复幂运算"是什么？这就是迭代幂运算（Tetration），也叫幂塔、超-4 运算。

定义 yn = nx = x ↑↑ n，即 n 个 x 从右往左嵌套取幂：

y0 = 1，  y1 = x，  yn = xyn−1

例如 y2 = xx，y3 = xxx，y4 = xxxx。注意幂运算不满足结合律，必须从最顶层（最右边）开始算。

与初等运算的层级关系
  1. 加法（超-1）：a + b = 重复计数 b 次
  2. 乘法（超-2）：a × b = 重复加 b 次
  3. 幂运算（超-3）：ab = 重复乘 b 次
  4. 迭代幂（超-4）：ba = 重复取幂 b 次
  5. 更高层：Pentation（超-5）、Hexation（超-6）……存在但极少使用

幂塔的导数公式

对 yn = x ↑↑ n 求导。由 yn = xyn−1 = eyn−1·ln x，用链式法则：

yn' = yn · ( yn−1' · ln x + yn−1x )

这是一个递推式。反复代入展开，可得显式求和公式：

yn' = 1x · n−1∑k=0 ( yn · yn−1 · … · yn−k ) · (ln x)k

即每一项是"从 yn 起连续 k+1 层的乘积"乘以 (ln x)k，再除以 x。

验证：前几层

  • n=1：y1 = x，y1' = 1。公式给出 1x·y1·(ln x)0 = 1x·x = 1 ✓
  • n=2：y2 = xx。直接求导 y2' = xx(ln x + 1)。公式给出 1x[y2·y1 + y2·y1·y0·ln x] = 1x[y2·x + y2·x·1·ln x] = y2(1 + ln x) ✓
  • n=3：y3 = xxx，y3' = y3·y2x · (1 + x·ln x + x·ln2x) ✓
幂塔增长极为迅猛：42 = 65536，52 已是天文数字。这也是迭代幂在实际计算中极少超过 4~5 层的原因

无穷幂塔与朗伯 W 函数

当层数趋于无穷时，幂塔 h(x) = xxx⋯ 满足不动点方程 h = xh。两边取对数：ln h = h ln x，即 (−h ln x)·e−h ln x = −ln x。用 W 函数解得：

h(x) = W(−ln x)−ln x

收敛域：无穷幂塔仅在 e−e ≈ 0.066 ≤ x ≤ e1e ≈ 1.444 时收敛。x = e1e 时 h = e；x = e−e 时 h = 1e。

特殊值

  • 0x = 1（空积约定，类似 x0 = 1）
  • 1x = x，2x = xx，3x = xxx
  • n1 = 1（任何层数，1 的任何次幂都是 1）
  • n2：1, 2, 4, 16, 65536, 265536, … 增长极其恐怖
迭代幂运算展示了"运算层级"的威力：每升一级，增长速度发生质变。幂塔的导数公式揭示了一个优雅结构——每层的贡献是"前面所有层的乘积"乘以 (ln x) 的幂次。无穷幂塔恰好是朗伯 W 函数的一个应用，收敛域 e−e ≤ x ≤ e1/e 是一个经典且反直觉的结果——x 不能太大也不能太小。

无穷幂塔与收敛性

令 y = xxx···（无穷层）。若收敛，则满足 y = xy。两边取对数：ln y = y ln x，即 (ln y)·e−ln y = ln x。令 u = −ln y，则 u·eu = −ln x，故 u = W(−ln x)，从而：

y = W(−ln x)−ln x

欧拉 1783 年证明：无穷幂塔收敛当且仅当 e−e ≤ x ≤ e1/e（约 0.066 ≤ x ≤ 1.445）。这个区间之窄令人意外——x=2 的无穷幂塔发散到无穷大，而 x=1.4 收敛到约 1.89。

边界值：x = e1/e 时，y = e；x = e−e 时，y = 1/e。

用 W 函数解幂塔方程

若已知无穷幂塔的值 y，求 x。由 y = xy，得 ln x = (ln y)/y，故 x = e(ln y)/y = y1/y。

经典问题：若 xxx··· = 2，求 x。由 y = 2，x = 21/2 = √2。验证：√2 的无穷幂塔确实等于 2（因为 (√2)2 = 2）。

陷阱：若令无穷幂塔 = 4，则 x = 41/4 = √2。但 √2 的无穷幂塔等于 2，不等于 4！这说明方程 y = xy 对同一个 x 可能有多个 y 解，只有落在收敛域内的解才有效。√2 的无穷幂塔收敛到 2（较小的解），而 4 是不稳定解。

超运算序列

迭代幂是超运算序列的第 4 级。完整序列（由 Goodstein 1947 年命名）：

级别名称运算示例
0后继a+13→4
1加法a+b重复后继 b 次
2乘法a×b重复加 b 次
3幂运算ab重复乘 b 次
4迭代幂ba重复取幂 b 次
5Pentationa ↑↑↑ b重复迭代幂 b 次
6Hexationa ↑↑↑↑ b重复 Pentation b 次

箭头记号 ↑ 由 Knuth 引入：a↑b = ab，a↑↑b = ba（迭代幂），a↑↑↑b = 重复迭代幂。每升一级增长速度暴增——3↑↑3 = 333 = 7,625,597,484,987，而 3↑↑↑3 是一个难以想象的巨大数字（远超可观测宇宙的原子数）。

关键结论
  1. 无穷幂塔 xxx··· 收敛 ⟺ e−e ≤ x ≤ e1/e
  2. 收敛值 y = W(−ln x)/(−ln x)，与朗伯 W 函数直接相关
  3. 幂塔导数递推：yn' = yn(yn−1'·ln x + yn−1/x)
  4. 超运算每升一级，增长速度发生质变，远超指数增长
004 · 分形几何 自相似图形的豪斯多夫维数

一条线段有 1 维，一个正方形有 2 维——这是直觉。但如果一个图形"比线粗一点，又比面薄一点"，它该有几维？分形几何给出了答案：维数可以是分数。

对严格自相似的分形图形，若整体放大 k 倍后可拆成 N 个与原集合全等的子集，则豪斯多夫维数：

d = ln Nln k
康托尔集每次挖去中间 1/3；科赫曲线每次将线段三等分、中间段替换为等边三角形的两边

经典例子

图形N（子集数）k（放大倍数）维数 d
线段221
正方形422
康托尔三分集23ln2/ln3 ≈ 0.631
科赫雪花43ln4/ln3 ≈ 1.262
谢尔宾斯基三角形32ln3/ln2 ≈ 1.585
分形维数可以不是整数——这正是"分形"名字的来源（fractal = fractional dimension）。科赫雪花的长度无限但面积有限，维数介于 1 和 2 之间。直觉上：康托尔集"比点多、比线少"，所以维数在 0 和 1 之间；科赫曲线"比线复杂、比面简单"，维数在 1 和 2 之间。
005 · 组合数学 有序整数分拆（Composition）

将正整数 n 拆为若干正整数的和，顺序不同视为不同分拆。记 an 为总数。

① 用 1 ~ m 分拆

  • n ≤ m：an = an−1 + … + a1 + 1
  • n > m：an = an−1 + … + an−m

m = 2 时退化为斐波那契递推。隔板法直接给出无限制时共 2n−1 种。

② 通项（特征方程法）

以 m=2 为例：λ2 = λ + 1，解得 λ1 = (1+√5)/2, λ2 = (1−√5)/2，

an = 1√5 · [ 1 + √52n+1 − 1 − √52n+1 ]
递推法和特征方程法给出了更一般的框架——当各部分大小有限制时，这套方法依然适用。

Composition vs Partition：顺序是否重要

有序分拆（Composition）与无序分拆（Partition）的核心区别在于顺序是否计入：

  • Composition（有序）：1+2 和 2+1 是两种不同分拆。n=3 的 composition 有 4 种：1+1+1, 1+2, 2+1, 3
  • Partition（无序）：1+2 和 2+1 视为同一种。n=3 的 partition 有 3 种：3, 2+1, 1+1+1

Composition 总数是 2n−1，Partition 总数 p(n) 增长更慢但没有简单闭式（渐近 p(n) ~ eπ√(2n/3)/(4n√3)，由 Hardy-Ramanujan 给出）。

隔板法的直观理解

把 n 写成 n 个 1 排成一排：1 1 1 … 1（共 n 个）。中间有 n−1 个空隙。在每个空隙可以选择"切"或"不切"，共 2n−1 种选择，每种选择对应一种 composition。例如 n=4：空隙 1__1__1__1，在第 1、3 个空隙切 → 1 | 1 1 | 1 → 1+2+1。

生成函数

composition 的生成函数极其简洁。由于每部分是正整数，且顺序重要，生成函数为：

C(x) = 11 − (x + x2 + x3 + …) = 11 − x/(1−x) = 1 − x1 − 2x

展开得 C(x) = 1 + x + 2x2 + 4x3 + 8x4 + …，系数 2n−1 正是 composition 数。若限制每部分 ≤ m，生成函数变为 1/(1 − x(1−xm)/(1−x))，对应前面的递推关系。

有限制的 composition

限制每部分 ≤ m：递推 an = an−1 + an−2 + … + an−m（n > m），特征方程 λm = λm−1 + λm−2 + … + 1。m=2 时退化为斐波那契，m→∞ 时退化为 2n−1。

限制每部分为奇数：生成函数 1/(1 − (x + x3 + x5 + …)) = 1/(1 − x/(1−x2))，解得递推 an = an−1 + an−2，又是斐波那契！

限制每部分为素数：生成函数 1/(1 − ∑p prime xp)，与哥德巴赫猜想相关——每个偶数能否写成两个素数之和，等价于素数 composition 的计数问题。

应用：概率与随机过程

composition 在概率论中自然出现。若 X1, X2, … 独立同分布取正整数值，则 P(X1 + … + Xk = n) 是将 n 分成 k 部分的某种加权 composition 数。几何分布的更新过程、骰子点数和的分布都与此相关。

例如：掷骰子直到点数和 ≥ 100，最后一次掷出的点数期望是多少？这个经典问题的答案是 7/2 ≈ 3.5，与直觉相反（不是 3），其分析用到了 composition 的对称性。

速查
  1. 无限制 composition 数：2n−1
  2. 分成 k 部分：C(n−1, k−1)（隔板法）
  3. 每部分 ≤ m：递推 an = Σi=1m an−i
  4. 生成函数：1/(1 − Σ允许值 xd)
006 · 数论 / 分析 伯努利数与欧拉-麦克劳林公式

伯努利数

通过生成函数定义：

xex − 1 = ∞∑n=0 Bnn! xn

前几个值：B0 = 1，B1 = −12，B2 = 16，B3 = 0，B4 = −130，B5 = 0，B6 = 142，…

重要性质：除 B1 外，所有奇数下标伯努利数为 0（B2n+1 = 0, n ≥ 1）。

递推公式

Bn = −1n+1 · n−1∑k=0 n+1k · Bk

冯·施陶特-克劳森定理

B2n 的分母恰好是所有满足 p−1 | 2n 的素数 p 的乘积：

denom(B2n) = ∏p−1 | 2n p

例如：denom(B2) = 6，denom(B4) = 30，denom(B6) = 42，denom(B12) = 2730。

欧拉-麦克劳林公式

连接离散求和与连续积分的桥梁：

b∑k=a f(k) = b∫a f(x) dx + f(a) + f(b)2 + m∑j=1 B2j(2j)! · [f(2j−1)(b) − f(2j−1)(a)] + Rm

经典应用

  • 调和级数：Hn = ln n + γ + 12n − 112n2 + …
  • 斯特林公式：ln n! ≈ n ln n − n + ln(2πn)2 + 112n − …
  • ζ(2n) = (−1)n+1 B2n (2π)2n2·(2n)!
伯努利数把幂和求和、欧拉-麦克劳林公式、黎曼 zeta 函数偶数值、费马大定理的正则素数等看似无关的领域串联在一起。分母的素数结构是数论中非常漂亮的结果。欧拉-麦克劳林公式是"求和 ≈ 积分 + 修正项"的精确化，修正项系数恰好是伯努利数——这也是伯努利数出现在那么多看似不相关公式里的原因。

Faulhaber 公式（幂和）

伯努利数最初来源于求前 n 个正整数的 k 次幂和。Faulhaber 公式：

n∑j=1 jk = 1k+1 k∑j=0 (−1)j k+1j Bj nk+1−j

前几个例子：

  • Σ j = n(n+1)/2 = (n2+n)/2
  • Σ j2 = n(n+1)(2n+1)/6 = (2n3+3n2+n)/6
  • Σ j3 = [n(n+1)/2]2 = (n4+2n3+n2)/4
  • Σ j4 = n(n+1)(2n+1)(3n2+3n−1)/30

注意 Σ j3 = (Σ j)2，这是一个经典恒等式。k 次幂和总是 k+1 次多项式，系数由伯努利数决定。

伯努利数与黎曼 zeta 函数

伯努利数与黎曼 zeta 函数在偶数点的值有精确关系：

ζ(2n) = (−1)n+1 B2n (2π)2n2 · (2n)!

前几个值：

  • ζ(2) = π2/6 ≈ 1.6449（巴塞尔问题，欧拉 1735 年解决）
  • ζ(4) = π4/90 ≈ 1.0823
  • ζ(6) = π6/945 ≈ 1.0173
  • ζ(8) = π8/9450

这说明 ζ(2n) 是 π2n 与有理数的乘积。但 ζ(2n+1)（奇数值）至今没有类似的简洁表达式——ζ(3)（Apéry 常数）已证明是无理数（Apéry 1978），但 ζ(5), ζ(7), … 的无理性仍未证明。

伯努利数的历史

雅各布·伯努利在《猜度术》（1713 年遗著）中系统研究了这些数，用于计算幂和。他发现了一个"通用公式"，可以一次性写出任意次幂和。据说他曾夸口说自己"用不到一刻钟"就算出了前 1000 个数的 10 次幂和，这在没有计算机的时代是惊人的。

值得注意的是，日本数学家关孝和（Seki Takakazu）几乎同时独立发现了相同的数。欧拉后来将伯努利数与 zeta 函数、三角级数联系起来，大大扩展了其应用范围。

欧拉-麦克劳林公式的余项与渐近级数

欧拉-麦克劳林公式中的余项 Rm 满足：

Rm = (−1)m+1 b∫a B2m({x})(2m)! f(2m)(x) dx

其中 B2m({x}) 是周期化的伯努利多项式。一个重要现象：当 m → ∞ 时，欧拉-麦克劳林级数通常发散，但前几项的截断误差极小——这是渐近级数的典型例子。对于调和级数，取前几项就能得到极高精度的 Hn 近似。

伯努利数速查

  2. 奇数项：B1 = −1/2，B2n+1 = 0（n ≥ 1）
  3. 前几个偶数项：B2=1/6, B4=−1/30, B6=1/42, B8=−1/30, B10=5/66
  4. 分母：denom(B2n) = ∏p−1|2n p（冯·施陶特-克劳森定理）

Gamma 函数

Γ(z) = ∫0+∞ tz−1 e−t dt   (Re z > 0)
  • 递推：Γ(z+1) = z Γ(z)；正整数：Γ(n+1) = n!
  • 特殊值：Γ(12) = √π

Beta 函数

B(p, q) = 1∫0 tp−1(1−t)q−1 dt = Γ(p) Γ(q)Γ(p+q)

与组合数的联系：B(k+1, n−k+1) = 1(n+1) nk。

三角函数积分的一般公式（华里士公式的推广）：

π/2∫0 sinmx cosnx dx = 12 · Γ(m+12) Γ(n+12)Γ(m+n+22)

余元公式（Euler 反射公式）

Γ(z) Γ(1−z) = πsin(π z)

令 z = 12 即得 Γ(12) = √π。揭示了 Gamma 函数与三角函数的深刻联系。

勒让德加倍公式

Γ(2z) = 22z−1√π · Γ(z) · Γ(z + 12)

华里士公式（Wallis 公式）

记 In = ∫0π/2 sinnx dx，分部积分得递推：

I2k = π2 · (2k−1)!!(2k)!!，  I2k+1 = (2k)!!(2k+1)!!

华里士乘积

π2 = ∞∏n=1 2n2n−1 · 2n2n+1

历史上第一个把 π 表示为有理数无穷乘积的公式。核心技巧：夹逼 sin2k+1x ≤ sin2kx ≤ sin2k−1x 积分后取极限。

斯特林公式（渐近展开）

Γ(z+1) ≈ zz e−z √(2π z)

正整数时即 n! ≈ nn e−n √(2π n)。华里士乘积可由此导出，反之华里士公式也可确定斯特林公式中的系数 √(2π)。

这几个公式构成了一个紧密网络：余元公式连接三角/复分析，加倍公式展示缩放性质，华里士公式把 π 表示为有理数无穷乘积，斯特林公式描述无穷远行为。Gamma 函数把"阶乘"从整数推广到全体实数，Beta 函数则是桥梁——许多含三角函数、幂函数的积分都能通过换元变成 Beta 积分再求值。

Bohr-Mollerup 定理：Gamma 的唯一性

为什么 Γ(n+1) = n! 的推广是 Γ(z) = ∫₀∞ tz−1e−tdt，而不是别的？Bohr-Mollerup 定理回答了这个问题：

定理：若函数 f 满足 (1) f(1)=1；(2) f(x+1)=x·f(x)；(3) ln f 是凸函数，则 f(x) = Γ(x)。

对数凸性（ln Γ(x) 凸）是关键约束。它保证了 Gamma 函数是阶乘的"最自然"推广——任何满足递推和对数凸性的函数只能是 Gamma。这是函数方程中"存在唯一性"的漂亮结果。

Weierstrass 乘积表示

Gamma 函数有无穷乘积形式：

1Γ(z) = z·eγz · ∞∏n=1 (1 + zn) · e−z/n

其中 γ 是欧拉-马斯刻若尼常数。这个形式清楚地展示了 Gamma 函数的极点：在 z = 0, −1, −2, … 处有一阶极点。收敛因子 e−z/n 保证了无穷乘积的收敛性（类似正弦函数的 Euler 乘积）。

更多特殊值

  • Γ(1/2) = √π
  • Γ(1/3) ≈ 2.678938535，Γ(2/3) ≈ 1.354117939
  • Γ(1/4) ≈ 3.625609908，Γ(3/4) ≈ 1.225416702
  • Γ(n+1/2) = (2n)!√π / (4n n!) = (2n−1)!!√π / 2n

余元公式给出 Γ(1/4)·Γ(3/4) = π√2，Γ(1/3)·Γ(2/3) = 2π/√3。

概率论中的应用

Gamma 函数和 Beta 函数在概率论中无处不在：

  • Gamma 分布：X ~ Gamma(α, β)，密度 f(x) = xα−1e−x/β / (βαΓ(α))。指数分布是 Gamma(1, β)，卡方分布是 Gamma(k/2, 2)。
  • Beta 分布：X ~ Beta(α, β)，密度 f(x) = xα−1(1−x)β−1 / B(α, β)，定义在 [0,1]。均匀分布是 Beta(1,1)。
  • Dirichlet 分布：Beta 分布的多变量推广，密度含多个 Gamma 函数的比值。
  • t 分布：密度中含 Γ((ν+1)/2)/(Γ(ν/2)√(πν))。

Beta(α, β) 的期望 = α/(α+β)，方差 = αβ/((α+β)²(α+β+1))。当 α=β=1 时退化为均匀分布；当 α, β 增大时分布越来越集中在均值附近。

余元公式的证明思路

Γ(z)Γ(1−z) = π/sin(πz) 可用多种方法证明。一种优雅的方法是利用 Weierstrass 乘积和正弦的 Euler 乘积：

sin(πz) = πz · ∞∏n=1 (1 − z2n2)

将 1/Γ(z) 和 1/Γ(1−z) 的 Weierstrass 乘积相乘，恰好得到 sin(πz)/(πz) 的倒数，故 Γ(z)Γ(1−z) = π/sin(πz)。另一个证明用 Beta 函数的积分表示和留数计算。

  2. 余元：Γ(z)Γ(1−z) = π/sin(πz)
  3. 加倍：Γ(2z) = 22z−1Γ(z)Γ(z+1/2)/√π
  4. Beta：B(p,q) = Γ(p)Γ(q)/Γ(p+q)
  5. 斯特林：Γ(z) ~ zz−1/2e−z√(2π)
008 · 数论 / 趣味常数 几个有趣的常数

① 布伦常数（Brun's constant）

所有孪生素数对的倒数之和：B2 = (13+15) + (15+17) + (11113) + … ≈ 1.902160583。有限值——布伦筛法证明了收敛性。而全体素数倒数和是发散的。

布伦常数最出名的"应用"是Intel Pentium FDIV bug（1994 年）。Thomas Nicely 在计算布伦常数时发现 Pentium 处理器的浮点除法单元有缺陷，导致某些双精度除法结果错误。Intel 最终耗资约 4.75 亿美元召回缺陷芯片。一个纯数学常数引发了计算机硬件史上最大的召回事件之一。

② 杜芬数（Dottie number）

cos x = x 的唯一实根：D ≈ 0.7390851332151607。超越数。从任意实数出发反复取余弦最终都收敛到此数——不动点定理的直观例子。

为什么从任意初值都收敛？因为 |cos'(x)| = |sin x| ≤ 1，且在不动点处 |sin D| ≈ 0.674 < 1，满足压缩映射条件（局部）。全局收敛需要更细致的分析，但数值实验和理论都确认了这一点。杜芬数与开普勒方程 E − e·sin E = M 密切相关——令 e = 1，方程变为 E − sin E = M，其解与杜芬数有关。

③ 康威常数（Conway's constant）

三个常数代表三种风味：布伦常数是"稀少但存在"；杜芬数是极简的超越数例子；康威常数展示"从简单规则中涌现出复杂代数结构"——外观数列规则简单到一句话就能说清，但它的增长常数却需要一个 71 次多项式才能刻画，这种"简单规则 → 复杂代数"的反差正是数学魅力所在。

④ 费根鲍姆常数（Feigenbaum constant）

混沌理论中的普适常数，由 Mitchell Feigenbaum 1975 年发现。考虑逻辑斯蒂映射 xn+1 = r·xn(1−xn)，当参数 r 增大时，系统经历倍周期分岔（1 周期 → 2 周期 → 4 周期 → 8 周期 → … → 混沌）。设分岔点参数为 r1, r2, r3, …，则相邻分岔间距之比收敛到：

δ = limn→∞ rn − rn−1rn+1 − rn ≈ 4.6692016091…

最震撼的是普适性：这个常数不只出现在逻辑斯蒂映射中，而是出现在所有具有单峰最大值的一维映射的倍周期分岔中。正弦映射、二次映射、任何"单峰"映射——分岔间距之比都收敛到同一个 δ。这意味着混沌的产生方式有普适规律，与具体系统细节无关。

另一个相关常数是 α ≈ 2.502907875，描述分岔图中相邻周期窗口的横向缩放比。δ 和 α 都是超越数（猜测，未证明），且没有已知的闭式表达式——只能通过数值计算得到。

费根鲍姆常数的发现是混沌理论的里程碑：它证明了看似随机的混沌行为背后存在精确的普适数学结构，开创了"重正化群"方法在混沌中的应用。

  • 内在（动态）：每次绕物体当前自身轴。R内 = RA(α)·RB(β)·RC(γ)。工程中最常用。

内在-外在等价定理

定理：按顺序 X1→X2→X3 的内在旋转 ≡ 按顺序 X3→X2→X1 的外在旋转，角度数值相等。

证明（两步情形，三步同理）：要证 内在 A→B = 外在 B→A。第一步绕自身 A 轴转 α，初始时自身 A 轴与世界 A 轴重合，矩阵 RA(α)。第二步绕旋转后的自身 B 轴转 β，用共轭变换：R绕自身B轴 = RA(α)·RB(β)·RA(α)−1。总矩阵 R内 = RA(α)·RB(β) = R外。证毕。

经典欧拉角 vs 泰特-布莱恩角

合法旋转顺序共 3×2×2 = 12 种，分两大类：

  • 经典欧拉角（6 种）：首尾同轴（Z-X-Z, Z-Y-Z, X-Y-X, X-Z-X, Y-X-Y, Y-Z-Y）。角度命名：进动/章动/自转。奇点：中间角 = 0° 或 180°
  • 泰特-布莱恩角（6 种）：三轴全不同（Z-Y-X, Z-X-Y, X-Y-Z, X-Z-Y, Y-X-Z, Y-Z-X）。角度命名：偏航/俯仰/滚转。奇点：中间角 = ±90°

Z-Y-X 内在旋转（航空标准）的前向向量：f = (cosα·cosβ, sinα·cosβ, −sinβ)T。

万向锁（Gimbal Lock）

中间角取到奇点值时，自由度从 3 退化为 2。

  • 数学本质：雅可比矩阵秩亏
  • 拓扑本质：SO(3) ≅ RP3，由毛球定理，不存在全局光滑的三参数参数化——任何用三个实数表示三维旋转的方式都必然有奇点
  • 规避：避开奇点区域，或改用四元数（SLERP 插值）

罗德里格斯旋转公式

由奥林德·罗德里格斯 1840 年提出。设旋转轴为单位向量 k，向量 v 绕 k 按右手定则逆时针旋转 θ：

v' = v cosθ + (k × v) sinθ + k (k·v)(1 − cosθ)

三项几何意义

  • v cosθ：垂直于轴的平面上的投影缩放
  • (k × v) sinθ：切向分量，实现"转向"
  • k(k·v)(1−cosθ)：平行于轴的分量修正，沿轴方向不变

垂直轴简化

k·v = 0 时第三项消失：v' = v cosθ + (k × v) sinθ。旋转完全在垂直平面内，与二维旋转一致。

坐标展开（轴 k = (−yr, xr, 0)，r = √(x2+y2)）：

x' = x cosθ + xzr sinθ，  y' = y cosθ + yzr sinθ，  z' = z cosθ − r sinθ

优势

  • 通用：适用于任意过原点旋转轴
  • 无分支：只有叉乘、点积、线性组合
  • 数值稳定：累计误差小
共轭变换是群论的核心技巧：绕"歪掉的轴"旋转 = 先转回标准位置 → 绕标准轴旋转 → 再转回去。不同行业对坐标轴和旋转顺序的约定差异极大（航空航天用 Z-Y-X 内在，Unity 用 Z-X-Y 左手系，ROS 用 X-Y-Z 外在），使用前务必确认约定。欧拉角与罗德里格斯公式是两种互补工具：欧拉角三角度参数化，直观但有奇点；罗德里格斯"轴+角"参数化，无奇点但参数冗余（轴有正负二义性）。

罗德里格斯公式的矩阵形式

令 K 为轴 k = (kx, ky, kz) 的反对称矩阵：

K = 0−kzkykz0−kx−kykx0

则旋转矩阵为：

R = I + (sin θ)K + (1 − cos θ)K2

这就是罗德里格斯旋转公式的矩阵形式。注意 K2 不是反对称矩阵，而是对称矩阵。这个展开式与 eθK = I + θK + θ²K²/2! + … 一致——因为 K3 = −K（凯莱-哈密顿定理的推论），所以级数可以重新组合成 sin θ 和 1−cos θ 的形式。

四元数：旋转的最优表示

单位四元数 q = (cos(θ/2), k·sin(θ/2)) 表示绕轴 k 旋转 θ。四元数乘法对应旋转的复合：q1q2 表示先做 q2 再做 q1。

  • 无万向锁：四元数是 S3 到 SO(3) 的双叶覆盖，无奇点
  • 紧凑：只需 4 个数（单位约束后 3 个自由度）
  • 插值光滑：SLERP（球面线性插值）给出最短测地线路径
  • 数值稳定：归一化即可，不会累积漂移

四元数 q 作用于向量 v 的公式：v' = q v q−1（将 v 视为纯虚四元数）。从四元数到旋转矩阵的转换：

R = 1−2(y²+z²)2(xy−zw)2(xz+yw)2(xy+zw)1−2(x²+z²)2(yz−xw)2(xz−yw)2(yz+xw)1−2(x²+y²)

其中 q = (w, x, y, z)。

SO(3) 的拓扑

三维旋转群 SO(3) 拓扑等价于实射影空间 RP3（3 维球面 S3 对对径点粘合）。这解释了：

  • 欧拉角有奇点：毛球定理说 S2 上无奇处非零切向量场，SO(3) 中的任何三参数参数化都必有奇点
  • 四元数是双覆盖：S3 → RP3，q 和 −q 表示同一旋转
  • 存在"扭转 4π 才能复原"的现象（如 Dirac 弦技巧）：RP3 的基本群是 ℤ₂，绕 2π 的路径是非平凡的，绕 4π 才同伦于平凡路径
旋转表示对比
  1. 欧拉角：3 参数，直观，有奇点（万向锁），插值困难
  2. 旋转矩阵：9 参数（约束后 3 自由度），无奇点，直接可用，参数冗余
  3. 轴+角（罗德里格斯）：4 参数（轴 3 + 角 1，模长约束后 3 自由度），无奇点，轴有正负二义
  4. 四元数：4 参数（单位约束后 3 自由度），无奇点，插值最优，需理解复数推广
010 · 抽象代数 赋范可除代数与维数定理

"n 维数系" = 实数域上的 n 维代数。要成为"好用的数系"，通常要求：有单位元 1、可除性（非零元有唯一逆元）、赋范性（|ab| = |a|·|b|）、（可选）交换律/结合律。保留性质越多，维数限制越严格。

为什么不存在三元数

用三次单位根构造三元数会产生零因子（两非零数相乘为 0），可除性失效。更深层：实系数奇次多项式必有实根，构造的代数天然可拆分。

弗罗贝尼乌斯定理

定理：实数域上有限维、结合、可除的代数只有 3 种——实数 ℝ（1 维）、复数 ℂ（2 维）、四元数 ℍ（4 维）。三维结合可除代数不存在。

赫尔维茨定理（Hurwitz 定理）

定理：实数域上有限维、赋范、交错的代数，维数只能是 1、2、4、8。

交错律：对任意 a, b，(aa)b = a(ab) 且 (ba)a = b(aa)——比结合律弱，但足以保证无零因子。

维数数系交换结合可除
1实数 ℝ✓✓✓
2复数 ℂ✓✓✓
4四元数 ℍ✗✓✓
8八元数 𝕆✗✗（交错）✓

16 维十六元数也存在，但连交错律都不满足，有大量零因子，已不具备"数系"的核心意义。

左正则表示

对 n 维数系中每个数 a，"左乘"操作 La(b) = a·b 是 n 维线性变换，可用 n×n 矩阵表示。数与矩阵一一对应，信息量等价——但全体矩阵比数系大得多，只有一小类特殊矩阵才对应数系元素。例如复数 a+bi 对应矩阵 a−bba，只是所有 2×2 矩阵中"旋转+等比缩放"那一小类。

赫尔维茨定理给出了"好用的数系"维数的完整答案：1、2、4、8，一个都不能多。这和 Bott 周期定理、除法代数的存在性紧密相关——1、2、4、8 这几个数在拓扑学中反复出现，背后是同一个深刻的数学结构。弗罗贝尼乌斯定理是赫尔维茨定理在"保留结合律"约束下的特例。

四元数的乘法

哈密顿 1843 年发现四元数，核心乘法规则：

i2 = j2 = k2 = ijk = −1

由此推出：ij = k, jk = i, ki = j；ji = −k, kj = −i, ik = −j。注意不可交换：ij = k 但 ji = −k。四元数 q = a + bi + cj + dk 的模 |q| = √(a²+b²+c²+d²)，且 |q₁q₂| = |q₁||q₂|。

共轭 q̄ = a − bi − cj − dk，逆 q−1 = q̄/|q|²。非零四元数都有逆，故是可除代数。

八元数：最后的数系

八元数由 Graves 和 Cayley 1843-1845 年独立发现。八元数有 8 个单位元：1, e1, e2, …, e7，每个 ei2 = −1。乘法由 Fano 平面（法诺平面）决定：7 个点和 7 条线，每条线上的三个元素满足 eiej = ±ek。

八元数既不交换也不结合，但满足交错律：(aa)b = a(ab) 和 (ba)a = b(aa)。这比结合律弱，但足以保证无零因子和可除性。八元数还满足 Moufang 恒等式，这是交错代数的核心性质。

八元数之所以重要，是因为它是最后一个赋范可除代数。16 维的十六元数（Sedenions）不再交错，有零因子，已不具备"数系"的核心意义。

为什么是 1、2、4、8？

维数 1、2、4、8 在数学中反复出现，背后有深刻原因：

  • 赋范可除代数（赫尔维茨）：仅 1, 2, 4, 8 维
  • 球面的可平行化：Sn 有处处线性无关切向量场 ⟺ n = 1, 3, 7（即 2, 4, 8 维数系的"虚部"球面）
  • 积空间上的 Hopf 纤维化：S1→S1, S3→S2, S7→S4, S15→S8 对应 ℝ, ℂ, ℍ, 𝕆 上的射影空间
  • Bott 周期性：拓扑 K 理论的周期为 8，与八元数相关

这些看似无关的定理实际上都指向同一个结构：实 Clifford 代数的周期性（周期 8）。1、2、4、8 不是巧合，而是实数域上代数结构的深刻限制。

弗罗贝尼乌斯定理的证明思路

弗罗贝尼乌斯定理（1877）说实数域上有限维结合可除代数只有 ℝ, ℂ, ℍ。证明核心：设 A 是这样的代数，考虑 A 中满足 x2 ≤ 0 的元素构成的子空间 V。若 dim V = 0，则 A ≅ ℝ；若 dim V = 1，则 A ≅ ℂ；若 dim V ≥ 2，取 V 中正交的 i, j，则 ij ∈ V 且与 i, j 正交，且 (ij)2 = −1。继续扩张可得四元数。若 dim V ≥ 4，类似构造会产生零因子，矛盾。故 dim V 只能是 0, 1, 3，对应 ℝ, ℂ, ℍ。

数系降级树
  1. 实数 ℝ（1维）：交换 + 结合 + 有序
  2. 复数 ℂ（2维）：交换 + 结合 − 有序
  3. 四元数 ℍ（4维）：− 交换 + 结合
  4. 八元数 𝕆（8维）：− 交换 − 结合（仅交错）
  5. 每升一级放弃一条基本性质，这是扩展数系的代价
011 · 高维几何 正多胞体与高维欧拉公式

正多胞体（Regular Polytopes）

二维有无穷多种正多边形，三维只有 5 种柏拉图立体——那么更高维呢？直觉上"维度越高约束越强，种类应该越少"，但实际规律出人意料：

维度 n正多胞体数量名称
2∞正多边形（正三角形、正方形、正五边形……）
35正四面体、正六面体、正八面体、正十二面体、正二十面体
46正五胞体、正八胞体(超立方体)、正十六胞体、正二十四胞体、正一百二十胞体、正六百胞体
≥ 53正单纯形、正超立方体、正正轴形（对应三维的正四面体、正方体、正八面体）

数量从二维无穷 → 三维 5 → 四维 6（反弹！） → 五维及以上 3（收敛稳定）。四维反而比三维多 1 种，并非"维度越高数量越少"的单调趋势。

核心洞察

任意维度都能构造出 3 种"基础型"（单纯形、超立方体、正轴形），它们的对称性最简洁普适。正十二面体、正二十面体、四维正二十四胞体这类"特殊型"只在低维有足够几何空间满足"所有面/胞全等、所有顶点对称"的严格条件。五维以上空间的几何约束强到只容得下 3 种基础型。

高维欧拉公式

经典 V − E + F = 2 在高维凸多胞体上的推广。

定理：对 n 维凸多胞体，设 Nk 为 k 维面数量（k=0 顶点，k=1 棱，k=2 面，…），则：

n−1∑k=0 (−1)k Nk = 1 − (−1)n

特例

  • 三维（n=3）：V − E + F = 2
  • 四维（n=4）：V − E + F − C = 0

右边 1−(−1)n 就是 n 维球的欧拉示性数。凸多胞体与球拓扑等价，故示性数相同。

五维以上几何对称约束强到只容得下 3 种基础型。正十二面体、正二十面体、四维正二十四胞体这类"特殊型"只在低维有足够几何空间满足严格对称条件。欧拉示性数是拓扑不变量——"形状的DNA"，不管怎么揉捏变形（不撕裂不粘合），V−E+F 永远不变。高维欧拉公式把它推广到任意维度，是代数拓扑学的基石之一。

Schläfli 符号

正多胞体用 Schläfli 符号 {p, q, r, …} 描述，每个数字表示"几个低一维面围成一个高一维面"：

  • 二维正多边形：{p}，p 条边
  • 三维正多面体：{p, q}，每个面是 p 边形，每个顶点连接 q 个面
  • 四维正多胞体：{p, q, r}，每个胞是 {p, q} 多面体，每条边周围有 r 个胞

五种柏拉图立体的 Schläfli 符号：{3,3} 正四面体，{4,3} 立方体，{3,4} 正八面体，{5,3} 正十二面体，{3,5} 正二十面体。

六种四维正多胞体：{3,3,3} 正五胞体，{4,3,3} 超立方体，{3,3,4} 正十六胞体，{3,4,3} 正二十四胞体，{5,3,3} 正一百二十胞体，{3,3,5} 正六百胞体。其中 {3,4,3} 正二十四胞体是四维独有的，没有三维对应——它由 24 个正八面体胞组成，每个顶点连接 6 个胞。

正二十四胞体：四维的特例

正二十四胞体（24-cell）是最神奇的正多胞体之一：

  • 由 24 个正八面体胞组成，24 个顶点，96 条棱，96 个三角形面
  • Schläfli 符号 {3,4,3}，自对偶
  • 可以铺满整个四维空间（类似三维中立方体铺空间）
  • 没有三维或更高维的对应物——只在四维存在

它的存在解释了为什么四维正多胞体有 6 种（比三维的 5 种多 1 种）：四维空间"恰好"容得下这个特殊的几何结构，而五维以上空间的约束太强，类似结构无法存在。

顶点图（Vertex Figure）

正多胞体的分类依赖于"顶点图"概念：在一个顶点附近用一个小球面截取，得到的截面是一个低一维的正多胞体（顶点图）。

例如：正十二面体 {5,3} 的顶点图是三角形（每个顶点连接 3 个五边形面）。若 {p, q} 是合法正多面体，则其顶点图必须是正 q 边形，且需满足 (p−2)(q−2) < 4。这给出了 5 种柏拉图立体的约束条件。

递归地，n 维正多胞体 {p₁, p₂, …, pn−1} 的顶点图是 {p₂, …, pn−1}，而其面是 {p₁, …, pn−2}。通过这种递归约束可以枚举所有维度的正多胞体。

高维欧拉公式的拓扑意义

欧拉示性数 χ = Σ(−1)kNk 是拓扑不变量。对凸多胞体，χ = 1−(−1)n：

  • n=2（多边形）：V − E = 0 → χ = 0
  • n=3（多面体）：V − E + F = 2 → χ = 2
  • n=4（多胞体）：V − E + F − C = 0 → χ = 0
  • n=5：V − E + F − C + H = 2 → χ = 2

奇偶维度交替出现 0 和 2，这是因为 n 维球 Sn 的欧拉示性数：χ(Sn) = 1 + (−1)n。凸多胞体与球同胚，故示性数相同。

这个公式是代数拓扑的起点——它把"计数"（顶点、棱、面的数量）与"拓扑"（形状的整体性质）联系起来。庞加莱后来将其发展为同调理论，χ 成为贝蒂数的交替和：χ = Σ(−1)kbk。

正多胞体分类
  1. 2 维：∞ 种（正 n 边形，n ≥ 3）
  2. 3 维：5 种（柏拉图立体）
  3. 4 维：6 种（多出正二十四胞体）
  4. ≥ 5 维：3 种（单纯形、超立方体、正轴形）
  5. 分类基础：Schläfli 符号 + 顶点图递归约束
012 分析 / 算子理论 EML 算子（Exp-Minus-Log）

EML 是 2026 年由波兰物理学家 Andrzej Odrzywołek 提出的二元数学算子，被誉为"连续数学中的 NAND 门"——仅需这一个算子搭配常数 1，通过递归嵌套组合，即可构造出科学计算器支持的全部初等函数，是目前已知最小的初等函数完备运算基元。

核心定义

算子全称 Exp-Minus-Log（指数-减-对数），接收两个输入 (a, b)，定义为：

EML(a, b) = ea − ln b

实数域下要求 b > 0；扩展到复数域时采用自然对数的主值分支，可支持三角函数、虚数单位 i 等构造。常数 1 是必要配套：利用 EML(a, 1) = ea − ln 1 = ea，可以消去对数项，单独提取出指数函数。

功能完备性原理

EML 的完备性来自"指数-对数体系的运算转换能力"+ 算子自带的减法，通过自举（Bootstrapping）逐层构造出所有运算：

  1. 基础层：从 EML 中分离出单目的 ex 和 ln x 函数
  2. 算术层：利用指数/对数的运算性质（乘除转加减），结合减法推导出加减乘除、幂、开方
  3. 超越层：通过复数域欧拉公式，从指数函数延伸出三角函数、双曲函数及相关常数

这完全类比数字电路中的 NAND 门：仅用一种逻辑门就能实现所有布尔运算，而 EML 是连续域中等价的最小完备算子。

基础运算的构造

  • 自然指数：ea = EML(a, 1)（代入 b=1 后 ln 1=0）
  • 常数 e：e = EML(1, 1)
  • 自然对数：需三层嵌套推导
  • 加法：通过"减法+取反"实现，纯 EML 表达式需约 9 次算子嵌套
  • 乘法：基于 eln a + ln b，先取对数求和再取指数，约 8 层嵌套
  • 三角函数：依托复数域欧拉公式 eix = cos x + i sin x

发现方法

EML 并非通过纯理论推导得出，而是作者通过系统性穷举搜索找到的：从标准科学计算器的 36 种基础运算/函数出发，逐步删减算子，验证剩余集合的完备性；枚举所有可能的二元初等函数组合，采用数值验证法（代入代数独立的超越常数，基于 Schanuel 猜想排除巧合相等）筛选候选；最终采用构造性证明，对每种初等函数都给出对应的 EML 二叉树表达式。

理论意义与工程局限

理论价值：首次证明仅用一个二元算子 + 一个常数即可生成全部初等函数，填补了连续数学领域的空白——离散逻辑有 NAND 作为完备基元，连续域此前始终需要多个基础函数。

工程局限：目前以理论价值为主，无法直接替代现有计算方案——多层指数、对数嵌套导致误差快速累积；基础加法都需 9 次 EML 运算，效率极低；实数域下对数输入必须为正，大量运算依赖复数域。

EML 算子是"极简主义"在数学中的极致体现：一个算子 + 常数 1 = 全部初等函数。它与 NAND 门（一个逻辑门 = 全部布尔运算）形成完美的离散-连续类比。虽然工程上不能直接用，但它揭示了初等函数体系的最小生成元，类似于群论中的生成元概念。

001 · 射影几何 彭赛列闭合定理

定理：给定两条二次曲线 C（外）和 D（内），从 C 上任一点出发，交替作 D 的切线交 C，若某起点经 n 次后回到起点（形成彭赛列 n 边形），则 C 上任意起点都能作出闭合 n 边形。闭合性只由两曲线相对位置决定，与起点无关。

彭赛列 n=3 情形：三角形内接于外圆 C、外切于内圆 D。若存在这样一个三角形，则从 C 上任意点出发都能作出闭合三角形。

特例：双心四边形

1(R−d)2 + 1(R+d)2 = 1r2

其中 R 为外接圆半径，r 为内切圆半径，d 为圆心距。

把"几何闭合"问题转化为纯粹"存在性"问题——只要找到一个闭合的，就有无穷多个。与椭圆光学性质、二次曲线配极理论紧密相关。

彭赛列闭合定理的历史

彭赛列（Jean-Victor Poncelet）1812 年随拿破仑远征俄国，战败被俘。在萨拉托夫战俘营的两年中，他在没有任何书籍的情况下重新推导并发展了射影几何，彭赛列闭合定理就是其中最重要的成果之一。他 1814 年获释回国后发表了《论图形的射影性质》（1822），开创了射影几何这门学科。

这个定理的惊人之处在于：闭合性是"全有或全无"的——要么所有起点都闭合，要么没有一个闭合。不存在"有些起点闭合、有些不闭合"的中间情形。

彭赛列定理与椭圆曲线

彭赛列闭合定理的现代证明与椭圆曲线密切相关。给定两条二次曲线 C 和 D，考虑从 C 上一点 P 出发作 D 的切线交 C 于 P' 的映射 T：P → P'。这个映射是 C 上的一个对合（involution），即 T(T(P)) = P。

彭赛列 n 边形的存在性等价于 Tn = identity。在椭圆曲线的语言中，这对应于椭圆曲线上某个点的阶为 n。由于椭圆曲线的群结构，"一个点阶为 n"要么对所有点成立（如果曲线本身有 n 阶挠点），要么对特定点成立——这正是彭赛列定理的代数本质。

Cayley 闭合条件

凯莱（Cayley）给出了判断两条二次曲线是否存在彭赛列 n 边形的代数条件。设两条二次曲线的方程为 C(x,y)=0 和 D(x,y)=0，考虑行列式 det(C + λD) 作为 λ 的多项式。Cayley 条件是这个多项式的某些系数满足特定的代数关系（涉及不变量）。

对于双心四边形（外接圆 + 内切圆），Cayley 条件简化为前面的公式：

1(R−d)2 + 1(R+d)2 = 1r2

这个公式是欧拉 1765 年发现的，称为欧拉双心四边形公式。

光学解释

彭赛列闭合定理有一个优美的光学解释：椭圆有"从一个焦点发出的光线经反射后汇聚到另一个焦点"的性质。推广到两条二次曲线：若光线在内曲线 D 上反射，且入射光在外侧曲线 C 上，则彭赛列定理说：若光线经过 n 次反射后回到起点，则无论从 C 上哪点出发，都能在 n 次反射后闭合。

这是 billiard（台球）问题中"可积性"的体现——彭赛列系统是完全可积的。

核心要点
  1. 闭合性是"全有或全无"：一个闭合 ⟹ 全部闭合
  2. 代数本质：椭圆曲线上点的阶
  3. Cayley 条件：判断两条二次曲线是否有彭赛列 n 边形
  4. 光学解释：双二次曲线台球系统的可积性
  5. 双心四边形公式：1/(R−d)² + 1/(R+d)² = 1/r²
002 · 几何 / 积分 霍迪奇定理

定理：取光滑凸闭合曲线 C，定长弦两端贴合 C 滑动一周。弦上定点把弦分为 p、q 两段，该定点划出内曲线 C'。则环形面积恒为：

SC − SC' = πpq

只与弦被分成的两段长度有关，与原曲线形状无关！p = q = L/2 时面积 = πL2/4，恰好等于直径为 L 的圆面积。

霍迪奇定理示意图。定长弦 AB 在凸曲线 C 上滑动，弦上点 P（分弦为 p、q）划出虚线内曲线 C′。环域面积恒为 πpq，与 C 的形状无关。
背后是积分几何中的运动学公式（克罗夫顿公式一族），和曲线整体形状无关。

定理的精确表述

设 C 是光滑凸闭合曲线，长为 L 的弦两端在 C 上滑动一周。弦上点 P 分弦为 p、q 两段（p+q = L），P 划出曲线 C'。则 C 与 C' 之间的环形面积为：

S(C) − S(C') = πpq

注意：面积差只与 p、q 有关，与 C 的形状、大小完全无关！即使 C 是不规则的土豆形，只要弦长固定，面积差就是 πpq。

证明思路

用格林公式和参数化。设弦两端点为 A(t)、B(t)（t 为参数），P = A + (p/(p+q))(B−A)。P 轨迹围成的面积：

S(C') = 12 ∮ (x dy − y dx)

将 P 的坐标代入展开，可以将 S(C') 表示为 S(C)、弦长 L、以及一个与曲线形状有关的积分项的组合。关键是那个"形状有关"的积分项在滑动一周后恰好抵消，只剩下 πpq 的差。

更深刻的证明利用克罗夫顿公式（Cauchy-Crofton formula）：平面上一条曲线的长度等于它与所有直线相交次数的积分（除以适当常数）。霍迪奇定理是这个公式在"弦滑动"场景下的推论。

特例验证

p = q = L/2：面积差 = π(L/2)² = πL²/4，恰好是直径为 L 的圆的面积。此时 C' 是 C 的"内平行曲线"（Minkowski 内偏移），面积差等于 πL²/4。

p → 0：面积差 → 0，P 趋近于 A，C' 趋近于 C 本身，符合预期。

C 是半径为 R 的圆：此时 C' 也是圆，半径为 √(R² − pq)？不对。实际上当 C 是圆时，弦长 L = 2√(R² − d²)（d 为圆心到弦的距离），P 到圆心的距离为 √(d² + (q−p)²/4)？让我们用定理验证：面积差 π(R² − r'²) = πpq，故 r' = √(R² − pq)。而弦长 L = 2√(R² − d²)，P 到圆心距离的平方 = d² + ((q−p)/2)² = (R² − L²/4) + (L²/4 − pq) = R² − pq。完全一致！

推广与变体

  • Steiner 公式：凸体向外偏移距离 r 后，面积 = A + Lr + πr²（L 为周长）。霍迪奇定理可视为其内偏移版本。
  • 高维推广：在 n 维空间中，超平面上的线段滑动有类似结果，涉及超球面面积。
  • Barbier 定理：宽度为 w 的等宽曲线周长 = πw，与形状无关。这也是积分几何中"形状无关"结果的另一例。

与克罗夫顿公式的联系

克罗夫顿公式：设 L(γ) 为曲线 γ 的长度，则

L(γ) = 14 ∬ n(γ, ℓ) dℓ

其中 n(γ, ℓ) 是 γ 与直线 ℓ 的交点数，dℓ 是直线空间上的自然测度。霍迪奇定理中的弦恰好是"与 C 相交于两点的直线"，而 P 的轨迹与这些直线的交点数决定了面积差。这揭示了霍迪奇定理本质上是一个积分几何结果——它不关心曲线的具体形状，只关心直线与曲线的相交统计。

霍迪奇定理要点
  1. 面积差 = πpq，与外曲线形状无关
  2. p=q=L/2 时，面积 = πL²/4（直径为 L 的圆面积）
  3. 本质：积分几何 / 克罗夫顿公式的推论
  4. 关联：Steiner 公式、Barbier 定理、Minkowski 内容
003 · 数论 伯特兰-切比雪夫定理

定理：对任意 n ∈ ℤ⁺，(n, 2n] 内必存在素数。

定理的由来

伯特兰（Joseph Bertrand）1845 年通过数值计算猜测：对任意 n > 1，区间 (n, 2n) 内至少有一个素数。他验证了 n ≤ 3,000,000 的所有情况。切比雪夫（Pafnuty Chebyshev）1852 年给出完整证明，因此定理以两人命名。

切比雪夫的证明思路是分析组合数 C(2n, n) 的素因子分解：若 (n, 2n] 内无素数，则 C(2n, n) 的所有素因子 ≤ n，通过估计其大小可导出矛盾。

切比雪夫证明的核心

组合数 C(2n, n) = (2n)!/(n!)² 满足：

4n2n+1 ≤ C(2n, n) ≤ 4n

如果 (n, 2n] 内没有素数，那么 C(2n, n) 的所有素因子 p ≤ n。对每个素数 p，它在 C(2n, n) 中的指数 vp(C(2n,n)) = Σ(⌊2n/pk⌋ − 2⌊n/pk⌋) ≤ logp(2n)。因此：

C(2n, n) = ∏p ≤ n pvp ≤ (2n)π(n)

其中 π(n) 是不超过 n 的素数个数。另一方面，C(2n, n) ≥ 4n/(2n+1)。如果 (n, 2n] 无素数，这两个不等式结合会给出矛盾（对足够大的 n）。

应用：n! 不是完全平方数

对 n ≥ 2，伯特兰定理保证 (n/2, n] 内存在素数 p。这个素数在 n! 中只出现一次（因为 2p > n），所以 vp(n!) = 1，是奇数。完全平方数的所有素因子指数都是偶数，故 n! 不可能是完全平方数。

类似地可以证明：n! 不是任何整数的 k 次幂（k ≥ 2），因为总存在某个素数的指数不是 k 的倍数。

应用：素数无穷的证明

假设素数有限，最大为 P。取 n = P，则 (P, 2P] 内有素数（伯特兰定理），与 P 最大矛盾。这个证明比欧几里得的经典证明更"构造性"——它不仅说素数有无穷多个，还给出了素数之间的间距上界：pn+1 < 2pn。

与素数定理的关系

素数定理（PNT，Hadamard & de la Vallée Poussin, 1896）说 π(x) ~ x/ln x。由此可知 (n, 2n] 内素数个数约为 n/ln n，随 n 增大趋向无穷。伯特兰-切比雪夫定理是 PNT 的一个弱化但精确的版本：它只保证至少一个素数，但对所有 n 成立，不依赖渐近。

更强的结果：

  • Nagura (1952)：n ≥ 25 时，(n, 6n/5] 内有素数
  • Dusart (2016)：n ≥ 468991632 时，(n, n(1+1/5000ln²n)] 内有素数
  • 孪生素数猜想（未证）：存在无穷多对差为 2 的素数

Erdős 的优雅证明

1932 年，19 岁的 Erdős 给出了伯特兰定理的一个简洁证明。他利用二项式系数的素因子分析，将区间分成三段：(n/3, n/2]、(n/2, n]、(n, 2n]。通过精确估计每段素数对 C(2n, n) 的贡献，证明若 (n, 2n] 无素数则 C(2n, n) 太小，矛盾。这个证明成为组合数论的经典范例。

伯特兰-切比雪夫定理要点
  1. (n, 2n] 内必有素数，对所有 n ≥ 1 成立
  2. 证明核心：分析 C(2n, n) 的素因子
  3. 推论：n! 不是完全幂；素数有无穷多个
  4. 与 PNT 的关系：PNT 给出 (n,2n] 内素数 ~ n/ln n 个
  5. Erdős 19 岁给出简洁证明，是组合数论经典
004 · 数论 勒让德公式与库默尔定理

勒让德公式

vp(n!) = ∞∑k=1 ⌊npk⌋ = n − Sp(n)p − 1

其中 Sp(n) 为 n 在 p 进制下各位数字和。组合数推广：vp(nm) = Sp(m) + Sp(n−m) − Sp(n)p − 1。

勒让德公式的等价形式证明

为什么 vp(n!) = (n − Sp(n))/(p−1)？

设 n 的 p 进制展开为 n = n0 + n1p + n2p² + …，其中 0 ≤ ni < p。则：

⌊n/p⌋ = n1 + n2p + n3p² + …
⌊n/p²⌋ = n2 + n3p + …

将所有项相加：vp(n!) = Σ⌊n/pk⌋ = n1 + n2(p+1) + n3(p²+p+1) + …

注意 (pk−1)/(p−1) = 1 + p + p² + … + pk−1，所以：

vp(n!) = ∑i≥1 ni · pi−1p−1 = (n−n0) − (Sp(n)−n0)p−1 = n−Sp(n)p−1

库默尔定理

定理：vp(nm) 等于 p 进制下 m + (n−m) = n 时的进位次数。

库默尔定理与勒让德公式的等价性

在 p 进制加法中，每发生一次进位，数字和减少 p−1（两个数字 a+b ≥ p，进位后变成 (a+b−p)，数字和从 a+b 变为 a+b−p+1，净减少 p−1）。设进位次数为 c，则：

Sp(m) + Sp(n−m) = Sp(n) + c(p−1)

代入勒让德公式的组合数版本：

vp(nm) = Sp(m)+Sp(n−m)−Sp(n)p−1 = c(p−1)p−1 = c

这就证明了库默尔定理：vp(C(n,m)) 恰好等于进位次数 c。

计算示例

例 1：v2(C(10, 3))。10 的二进制是 1010，3 的二进制是 0011，7 的二进制是 0111。计算 3 + 7 = 10（二进制：0011 + 0111 = 1010），进位次数：第 0 位 1+1=2→进位，第 1 位 1+1+1=3→进位，第 2 位 0+1+1=2→进位，共 3 次进位。所以 v2(C(10,3)) = 3。验证：C(10,3) = 120 = 2³ × 15，确实 v2 = 3。

例 2：v5(C(25, 10))。25 的五进制是 100，10 是 20，15 是 30。20 + 30 = 100（五进制），第 0 位 0+0=0，第 1 位 2+3=5→进位 1，共 1 次进位。所以 v5(C(25,10)) = 1。

应用：判断组合数是否被 p 整除

C(n, m) ≡ 0 (mod p) ⟺ p 进制下 m + (n−m) 有进位 ⟺ 存在某一位 mi > ni（因为如果 mi ≤ ni 对所有 i 成立，则加法无进位）。

这直接与卢卡斯定理（005）联系起来：卢卡斯定理说 C(n,m) ≡ ∏C(ni, mi) mod p。若某位 mi > ni，则 C(ni, mi) = 0，整个乘积 ≡ 0 mod p。两个定理说的是同一件事的不同侧面。

历史注记

勒让德公式由勒让德（Adrien-Marie Legendre）1808 年在《数论》中给出。库默尔定理由库默尔（Ernst Kummer）1852 年发现，他当时研究的是费马大定理中理想数的分解。库默尔定理是组合数论中最优雅的结果之一——把素因子指数这个数论问题，转化为进位次数这个组合问题。

核心要点
  1. vp(n!) = (n − Sp(n))/(p−1)，数字和形式便于计算
  2. vp(C(n,m)) = p 进制加法进位次数（库默尔）
  3. C(n,m) ≡ 0 mod p ⟺ 某位 mi > ni（与卢卡斯定理等价）
  4. 每进位一次数字和减少 p−1，对应 vp 增加 1
005 · 数论 / 组合 卢卡斯定理

定理：设 p 为素数，n, m 的 p 进制展开为 n = ∑i nipi，m = ∑i mipi，则

nm ≡ ∏i nimi   (mod p)

若某位 mi > ni，则 nimi = 0，原式模 p 为 0。

卢卡斯定理的证明

利用多项式同余。在模 p 下，费马小定理给出 (1+x)p ≡ 1+xp (mod p)，更一般地 (1+x)pk ≡ 1+xpk (mod p)。因此：

(1+x)n = (1+x)n0+n1p+n2p²+… ≡ ∏i (1+xpi)ni (mod p)

左边 xm 的系数是 C(n, m)。右边 xm = xm0+m1p+… 的系数是各因子中 xmipi 的系数之积，即 ∏C(ni, mi)。比较两边 xm 系数即得卢卡斯定理。

计算示例

例：求 C(1234, 789) mod 5。

1234 的五进制：1234 = 1×625 + 4×125 + 4×25 + 1×5 + 4 = (14414)5

789 的五进制：789 = 1×625 + 1×125 + 1×25 + 2×5 + 4 = (11124)5

逐位比较：mi ≤ ni 对所有位成立（1≤1, 1≤4, 1≤4, 2≤1? 不！2 > 1）。所以第 3 位 m3=2 > n3=1，C(n3, m3) = C(1, 2) = 0。因此 C(1234, 789) ≡ 0 (mod 5)。

验证：789 + 445 = 1234，五进制 (11124)5 + (03320)5 = (14414)5，第 3 位 1+3=4→无进位？等等，让我重新算。实际上用库默尔定理：789 + 445 = 1234，五进制加法中第 1 位 2+2=4→无进位，第 2 位 1+3=4→无进位，第 3 位 1+1=2→无进位，第 4 位 1+0=1→无进位。但卢卡斯定理说 C(1234,789) ≡ 0 mod 5？这与库默尔定理矛盾。让我重新检查五进制转换：1234/5=246余4，246/5=49余1，49/5=9余4，9/5=1余4，1/5=0余1。所以 1234 = (14414)5。789/5=157余4，157/5=31余2，31/5=6余1，6/5=1余1，1/5=0余1。所以 789 = (11124)5。逐位：n=(1,4,4,1,4), m=(1,1,1,2,4)。第 4 位（从右数第 4 位，即 p³ 位）n=1, m=2，2 > 1，所以 C(1,2)=0。用库默尔：m + (n−m) = 789 + 445 = 1234。445/5=89余0，89/5=17余4，17/5=3余2，3/5=0余3。所以 445 = (03240)5。789=(11124)5 + 445=(03240)5：第0位4+0=4，第1位2+4=6=1×5+1→进位1，第2位1+2+1=4，第3位1+3=4，第4位1+0=1。进位1次。所以 v5(C(1234,789))=1，确实 ≡ 0 mod 5。卢卡斯定理正确！

卢卡斯定理的推广：Granville 定理

卢卡斯定理只适用于模素数 p。Andrew Granville 1997 年将其推广到模素数幂 pk，涉及更复杂的 p 进制块分析。对于模合数的情况，通常使用中国剩余定理分解为模素数幂后分别处理。

与帕斯卡三角模 p 的关系

卢卡斯定理揭示了帕斯卡三角模 p 的分形结构。例如模 2 时，C(n, m) 为奇数当且仅当 m 的二进制位是 n 的二进制位的子集（即 m & n = m）。这产生了著名的谢尔宾斯基三角形分形图案。

模 p 的帕斯卡三角具有自相似性：第 0 到 p−1 行是基础块，第 p 到 2p−1 行是基础块的拷贝，中间插入 0，以此类推。这种分形结构是卢卡斯定理的直接推论。

卢卡斯定理要点
  1. C(n,m) mod p = ∏C(ni, mi) mod p（p 进制逐位相乘）
  2. 某位 mi > ni ⟹ C(n,m) ≡ 0 mod p
  3. 与库默尔定理等价：有进位 ⟺ 某位 mi > ni
  4. 模 2 时：C(n,m) 为奇 ⟺ m 的二进制是 n 的子集
  5. 帕斯卡三角模 p 呈现分形（谢尔宾斯基三角形）
006 · 代数 多项式消次与三次方程求根公式

n 次多项式消次

令 x = t − a1n a0，消去 xn−1 项

这是 Tschirnhaus 变换的最简形式。对首一多项式 xn + an−1xn−1 + …，令 x = t − an−1/n，可消去 tn−1 项。其原理是：多项式根的和为 −an−1，平移后根的和变为 0。

三次方程的历史

三次方程求根公式是数学史上最具戏剧性的发现之一。16 世纪意大利：

  • Scipione del Ferro（约 1515）发现 x³+px=q 的解法，但秘而不宣
  • Niccolò Tartaglia（1535）独立发现，在数学竞赛中大胜
  • Gerolamo Cardano（1545）在《大术》中发表，承诺保密但食言
  • Lodovico Ferrari（Cardano 的学生）随后发现四次方程解法

Cardano 在发表公式时承认了 del Ferro 和 Tartaglia 的贡献，但 Tartaglia 认为 Cardano 背信弃义，引发了一场著名的数学论战。

卡尔达诺公式

三次方程 ax3+bx2+cx+d=0，换元 x = y − b3a 化为 y3+py+q=0。令 y = u+v，设 uv = −p3，则 u3+v3 = −q，u3v3 = −p327。A=u3, B=v3 是 t2+qt−p327=0 的根。

判别式 Δ = q24 + p327

  • Δ > 0：一实根 + 一对共轭复根
  • Δ = 0：重根，三实根
  • Δ < 0：三互不等实根（不可约情形）

记 ω = −12 + i√32（三次单位根），三根为：

y1 = 3√A + 3√B，  y2 = ω3√A + ω23√B，  y3 = ω23√A + ω3√B

不可约情形（Casus Irreducibilis）

当 Δ < 0 时，三次方程有三个互异实根，但卡尔达诺公式中 A 和 B 是共轭复数，必须对复数开立方才能得到实根。这就是著名的"不可约情形"——实根不能用实数的根式表示，必须借助复数。

这是数学史上虚数被认真对待的起因之一。在此之前，负数的平方根被视为"不可能的数"，但三次方程的解法表明，即使最终答案是实数，中间步骤也必须经过复数。Cardano 本人对此感到困惑，称之为"诡辩的量"（sophistic quantities）。

不可约情形的三角解法：当 Δ < 0 时，设 p = −3r²，q = −2r³cos θ，则三根为：

yk = 2r cos(θ + 2πk3),   k = 0, 1, 2

这个解法用三角函数绕过了复数，但本质上三次单位根与三等分角密切相关。

四次方程简述

Ferrari 发现了四次方程的解法。对 x⁴ + ax³ + bx² + cx + d = 0，消去三次项后用配方法化为两个二次方程之积。关键是引入一个辅助参数 y，使得方程可写成 (x² + px + q)² − (rx + s)² = 0 的形式，然后求解一个三次预解方程（resolvent cubic）。

四次方程的解法依赖于三次预解方程，这解释了为什么五次及以上方程没有一般根式解（阿贝尔-鲁菲尼定理，伽罗瓦理论）——根式解的存在性与对称群的可解性相关，而 S5 不可解。

判别式的一般理论

n 次多项式 f(x) = a0∏(x−ri) 的判别式定义为：

Δ = a02n−2 ∏i<j (ri − rj)2

Δ = 0 ⟺ 有重根。对二次方程 Δ = b²−4ac，对三次方程 Δ = −4p³−27q²（注意符号约定可能不同）。判别式是多项式系数的对称多项式，可以用结式（resultant）计算：Δ = (−1)n(n−1)/2 a0−1 Res(f, f')。

核心要点
  1. 消次变换：x = t − an−1/n，根的和归零
  2. 三次方程：换元 y = u+v，解二次预解方程
  3. 不可约情形（Δ < 0）：三实根必须用复数开立方表示
  4. 不可约情形是虚数被接受的历史起因
  5. 四次方程可解，五次及以上无一般根式解（伽罗瓦理论）

008 · 组合数学 多项式定理

(a+b)2 = a2+2ab+b2，(a+b+c)2 = a2+b2+c2+2ab+2ac+2bc——那么 (a+b+c+d+…)n 怎么展开？多项式定理给出答案。

(x1 + x2 + … + xm)n = ∑n1+…+nm=n n!n1! n2! … nm! · x1n1 x2n2 … xmnm

求和遍历所有满足 n1+n2+…+nm=n 的非负整数组。系数 n!n1! n2! … nm! 称为多项式系数，记作 nn1, n2, …, nm。

层级关系
  1. 多项式定理（m 个变量）⊃ 三项式定理（m=3）⊃ 二项式定理（m=2）
  2. 系数 = 把 n 个不同位置分成大小为 n1,…,nm 的 m 组的方案数
  3. 系数和 = mn（令所有变量取 1）

特例

  • m=2（二项式定理）：系数 nk, n−k = nk
  • m=3（三项式定理）：(x+y+z)n = ∑a+b+c=n n!a! b! c! xaybzc

完整展开示例（视觉震撼）

把公式全部写开，能直观感受项数爆炸。(a+b+c)4 共 15 项：

(a+b+c)4 = a4 + b4 + c4
  + 4(a3b + a3c + ab3 + b3c + ac3 + bc3)
  + 6(a2b2 + a2c2 + b2c2)
  + 12(a2bc + ab2c + abc2)

再看 (a+b+c+d)4，变量只多一个，项数暴增到 35 项：

(a+b+c+d)4 = a4 + b4 + c4 + d4
  + 4(a3b + a3c + a3d + ab3 + b3c + b3d + ac3 + bc3 + c3d + ad3 + bd3 + cd3)
  + 6(a2b2 + a2c2 + a2d2 + b2c2 + b2d2 + c2d2)
  + 12(a2bc + a2bd + a2cd + ab2c + ab2d + b2cd + abc2 + ac2d + bc2d + abd2 + acd2 + bcd2)
项数增长规律
  1. (a+b)4：5 项（二项式）
  2. (a+b+c)4：15 项（三项式）
  3. (a+b+c+d)4：35 项（四项式）
  4. (a+b+c+d+e)4：70 项（五项式）
  5. 通项：(x1+…+xm)n 的项数 = n+m−1m−1（隔板法）

组合意义

把 n 个因式相乘，每个因式选一个变量。要得到 x1n1x2n2…xmnm，相当于把 n 个位置分成大小为 n1, n2, …, nm 的 m 组——等价于多重集合 {n1·x1, n2·x2, …, nm·xm} 的全排列数。

系数和

令全部变量取 1：

∑n1+…+nm=n nn1, n2, …, nm = mn

m=2 时即二项式系数和 2n。

带系数的展开

若括号内带系数，如 (2a − b + 3c)5 中 a2b2c1 的系数：

52, 2, 1 · 22 · (−1)2 · 31 = 5!2! 2! 1! · 4 · 1 · 3 = 360

推导思路

把前 m−1 个变量打包：[(x1+…+xm−1) + xm]n，先用二项式定理展开，再对 (x1+…+xm−1)n−nm 递归套用多项式定理——本质上是反复使用二项式定理。

概率论中的多项分布

多项式定理最直接的应用是多项分布（multinomial distribution）。设一次试验有 m 种可能结果，概率分别为 p1, p2, …, pm（Σpi = 1）。独立重复 n 次试验，第 i 种结果出现 ni 次的概率为：

P(n1, n2, …, nm) = nn1, n2, …, nm p1n1 p2n2 … pmnm

这正是 (p1+p2+…+pm)n = 1n = 1 展开式中的一项。多项式系数给出了将 n 次试验分成 m 组的方式数。

当 m=2 时，多项分布退化为二项分布。当 m=6 且 pi=1/6 时，就是掷 n 次骰子的分布。

生成函数视角

从生成函数的角度看，(x1+…+xm)n 中 x1n1…xmnm 的系数就是"从 n 个因子中各选一个变量，使得 xi 被选 ni 次"的方式数。

更一般地，指数生成函数与多项式系数的关系：

(x1+x2+…+xm)n = n! · [tn] ∏i=1m etxi

其中 [tn] 表示取 tn 的系数。这揭示了多项式定理与指数型生成函数的内在联系。

与有序分拆（Composition）的关系

注意区分两个概念：

  • 多项式系数：把 n 个不同的位置分成大小为 n1, …, nm 的组，系数 = n!/(n1!…nm!)
  • 有序分拆（composition）：把 n 拆成有序的正整数之和，方案数 = 2n−1
  • 无序分拆（partition）：把 n 拆成无序的正整数之和，无简单公式

多项式系数与 composition 的联系：(x1+…+xm)n 的项数 C(n+m−1, m−1) 是"允许零的有序分拆"数（weak composition）。

多项式系数的递推关系

类似二项式系数的帕斯卡递推，多项式系数满足：

nn1, n2, …, nm = n−1n1−1, n2, …, nm + n−1n1, n2−1, …, nm + … + n−1n1, n2, …, nm−1

组合意义：考虑最后一个位置分给哪个变量——分给 x1 则第一项，分给 x2 则第二项，依此类推。

恒等式：范德蒙德卷积的推广

二项式的范德蒙德卷积 ΣC(a,k)C(b,n−k) = C(a+b, n) 可以推广到多项式：

∑k1+…+km=n a1k1a2k2…amkm = a1+a2+…+amn

这是 (1+x)a1(1+x)a2…(1+x)am = (1+x)a1+…+am 两边 xn 系数相等的结果。

多项式定理是二项式、三项式的终极推广。多项式系数在组合数学、概率论（多项分布）、统计力学中频繁出现。与"有序整数分拆"不同：多项式系数是把 n 个不同位置分成指定大小的组，而 composition 是把 n 拆成有序的正整数之和。
009 数论 / 丢番图方程 斐波那契数列中的完全幂（Bugeaud–Mignotte–Siksek 定理）

定理：斐波那契数列 Fn（F₀=0, F₁=1, Fₙ₊₂=Fₙ₊₁+Fₙ）中的完全幂（即形如 yk，k ≥ 2 的数）只有以下五个：

  • F₀ = 0 = 0k
  • F₁ = F₂ = 1 = 1k
  • F₆ = 8 = 23
  • F₁₂ = 144 = 122

同一篇论文还解决了卢卡斯数列 Lₙ（L₀=2, L₁=1）的对应问题：只有 L₁ = 1 和 L₃ = 4 = 2²。

一个 40 年悬案

这个问题看似初等，却悬而未决超过 40 年，逐步攻克的时间线：

  • 1951，Ljunggren：平方数只有 0, 1, 144
  • 1964，Cohn：重新发现平方数结果
  • 1969，London & Finkelstein：立方数只有 0, 1, 8
  • 2003 前：已知指数 p ≤ 17 或 p ≥ 5.1×1017 时无更高次幂，但中间巨大空缺无法处理
  • 2006，Bugeaud, Mignotte, Siksek：完全解决所有指数

论文信息

Y. Bugeaud, M. Mignotte, S. Siksek, "Classical and Modular Approaches to Exponential Diophantine Equations I. Fibonacci and Lucas Perfect Powers", Annals of Mathematics 163 (2006), 969–1018. 证明完成于 2003 年。

证明方法（几句话版）

证明的惊人之处在于：问题本身极其初等，却动用了 20 世纪最深刻的数论工具——Baker 理论（线性形式中的对数，给出指数上界）与模方法（源自 Wiles 证明费马大定理的工具链，构造 Frey 椭圆曲线 Y² = X³ + LₙX² − X，应用 Ribet 的 Level-Lowering 定理）的结合。两者配合排除了所有可能的解。这是模方法首次成功应用于"非费马型"的指数丢番图方程。

  • 反差之美：最初等的数列 + 最深奥的方法 = 数学魅力的极致体现
  • 方法论突破：证明了费马大定理的工具链并非只适用于费马方程，而是处理指数丢番图方程的通用武器

这个定理是"简单问题 + 深刻证明"的典范。斐波那契数列小学生都能写出来，但要证明其中只有 0、1、8、144 是完全幂，需要用到 20 世纪末才成熟的模形式理论。它发表在数学最顶级期刊 Annals of Mathematics 上，足见分量。顺便一提，Fₙ ± 1 是完全幂的情况也被同一组作者解决：解为 Fₙ = 0, 1, 2, 3, 5, 8。
010 数论 / 调和数 Theisinger 定理与 Kűrschák 定理（调和数非整数）

Theisinger 定理（1915）

定理：对任意整数 n ≥ 2，调和数 Hn = 1 + 1/2 + 1/3 + … + 1/n 不是整数。

证明核心：在 1, 2, …, n 中，存在唯一的 2 的最高次幂 2k（即最大的 2 的幂 ≤ n）。这个 2k 在 Hn 的分母中只出现一次——其他所有数的 2-adic 赋值都小于 k。因此通分后，只有 1/2k 这一项的分子是奇数，其余各项的分子都是偶数。所有分子之和为奇数，不可能被分母的 2k 整除，故 Hn 不是整数。

Kűrschák 定理（1918，加强版）

定理：对任意整数 1 ≤ m < n，差调和数 Hn − Hm = 1/(m+1) + 1/(m+2) + … + 1/n 永远不是整数。

也就是说：任意一段连续的单位分数和（至少两项），都不可能是整数。Theisinger 只是从 1 开始的前缀和，Kűrschák 推广到了任意连续区间。

简短对比

  • Theisinger：从 1 开始的调和部分和 Hn，n ≥ 2 时不是整数
  • Kűrschák：任意连续一段单位分数之和，项数 ≥ 2，必不是整数

后续推广

Erdős 进一步推广到等差数列倒数和：Σ 1/(a + kd) 在适当条件下也不能为整数。Kűrschák 本人还是赋值（valuation）理论的建立者，是 p 进赋值的先驱——这个定理的证明本质上就是 2-adic 赋值的应用。

核心要点
  1. Theisinger：Hn（n ≥ 2）不是整数，证明用 2-adic 赋值
  2. Kűrschák：任意连续单位分数和（≥2项）不是整数
  3. 关键：区间中存在唯一的 2 的最高次幂，使分子为奇数
  4. Erdős 推广到等差数列倒数和

  • 四位分节大单位：万(104)、亿(108)、兆(1012)……每 4k 位一个，各占 1 字

渐近尺度

N ≈ 10m ⟹ ln N = m ln 10。中文按 4 位分块，共 ⌈m4⌉ 块。每块最多 4 个数字 + 3 个权（千、百、十）= 7 字，再加块尾大单位 1 字。故每块字数为常数，不随 m 增长：

f(N) = Θ(m4) = Θ(ln Nln 10)

比值 f(N)ln N 是有界量，但普通极限不存在——在两个常数之间震荡。

核心结论
  1. 量级：f(N) ∝ log10 N，即汉字数与十进制位数成正比
  2. 上极限：全为 9 时取得，limsup = 2ln 10 ≈ 0.869
  3. 下极限：1 后全 0 时取得，liminf = 14 ln 10 ≈ 0.109
  4. 结论：比值在 0.109 ~ 0.869 之间震荡，不收敛

上极限（全为 9，如 9999…9999）

N = 104k − 1，即 4k 个 9。每块"九千九百九十九"= 7 字，k 块共 7k 字；块尾单位"万、亿…"共 k−1 个（末尾无单位）。总字数 f ≈ 8k：

limsupN→∞ f(N)ln N = 8k4k ln 10 = 2ln 10 ≈ 0.869

下极限（1 后面全 0，如一亿、一兆）

N = 104k，读作"一兆…亿万"，仅 k+1 字（1 个数字 + k 个大单位）：

liminfN→∞ f(N)ln N = k4k ln 10 = 14 ln 10 ≈ 0.109

含"零"的情形

数字中间出现 0 时插入"零"字，但每块内部最多插 3 个零，每块总字数仍为常数。量级不变，f(N) = O(log N)，上下极限只略增大，仍无单一极限。

与英文对比

英文按 3 位分节（thousand, million, billion…），故 limsup 常数分母为 3 ln 10。中文 4 位分节是根源差异。

具体数值示例

让我们看一些具体数字的中文读数长度，直观感受震荡：

N = 100"一百"2 字f/ln N ≈ 2/4.605 ≈ 0.434
N = 999"九百九十九"5 字f/ln N ≈ 5/6.908 ≈ 0.724
N = 10000"一万"2 字f/ln N ≈ 2/9.210 ≈ 0.217
N = 9999"九千九百九十九"7 字f/ln N ≈ 7/9.210 ≈ 0.760
N = 108"一亿"2 字f/ln N ≈ 2/18.42 ≈ 0.109
N = 108−1"九千九百九十九万九千九百九十九"15 字f/ln N ≈ 15/18.42 ≈ 0.814

可以看到，同样数量级的数（108 和 108−1），读数长度相差近 8 倍。比值在 0.109（下极限）和 0.869（上极限）之间震荡，且永远不会收敛到一个确定的值。

更精确的震荡分析

比值 f(N)/ln N 的震荡并非随机，而是由 N 的十进制表示决定：

  • 当 N 的各位都是 9 时，每块 4 位需要 7 字（四千九百九十九），加上块间单位，比值逼近上极限 0.869
  • 当 N = 104k 时，只需 k+1 字，比值逼近下极限 0.109
  • 对于"随机"的 N（各位均匀分布），平均每块约 4×0.5 + 3×0.9 ≈ 4.7 字（数字出现概率约 0.5，权位出现概率约 0.9），比值约为 0.4~0.5

因此，虽然极限不存在，但比值的"期望值"在 0.4~0.5 之间，远低于上极限。

自指读数谜题

一个有趣的衍生问题：是否存在一个数 N，它的中文读数恰好有 N 个字？例如：

  • N = 1："一" = 1 字 ✓（平凡解）
  • N = 2："二" = 1 字 ✗
  • N = 3："三" = 1 字 ✗
  • ...

由于 f(N) = Θ(log N)，当 N > 10 时 f(N) < N，所以除了 N=1 外不存在这样的数。更有趣的是"读数长度的读数长度"问题：设 g(N) = f(f(N))，即 N 的读数长度的读数长度。由于 f(N) = Θ(log N)，g(N) = Θ(log log N)，增长更慢。

推广：其他语言和进制

这个问题可以推广到任何语言和进制：

  • 英文：3 位分节，limsup = 2/(3 ln 10) ≈ 0.290，但英文单词长度不一（one=3, seven=5, twenty=6），分析更复杂
  • 日文：与中文类似，4 位分节（万、億、兆），常数相同
  • 二进制：每 4 位一个 nibble，但二进制没有"大单位"概念，分析完全不同

这个问题的本质是：数值大小的增长是指数级的，而语言表示的增长是线性的（与位数成正比），所以比值 f(N)/N → 0，但 f(N)/log N 在常数间震荡。

这个问题把语言文字规则转化为渐近分析，很适合体会"离散结构的对数尺度"。一个有趣的对照："一亿"只有 2 个字，"99999999"却要读约 16 个字——数差不多大，读法长度差了 8 倍。
002 · 几何 / 搜索论 雾中船问题（Bellman 失海问题）

船距直线海岸线垂直距离 1km，起雾后完全不知道岸的方位。设计一条连续航行路径，保证无论岸是哪条距自己 1 的直线都能碰到，且使最坏情况下的总航程最小（极小极大优化 min-max）。

几何转化

所有可能的海岸线 = 单位圆 r=1 的全部切线。一条直线到原点距离为 1 ⟺ 它是单位圆的切线。路径必须与每条切线在某点相交。目标：

minγ { maxτ [路径 γ 走到与切线 τ 相交的路程] }
虚线圆为单位圆（船到岸距离=1），四条灰线为单位圆的切线（可能的海岸线）。最优路径（红色）是从原点出发、一边旋转一边缓慢向外扩张的螺旋，在圆外拦截切线——而非沿圆周走一圈。

朴素方案

  • 方案 1：朝任一方向直行 1km——若刚好朝岸则 1km 到，最坏方向垂直于岸则永远碰不到，不可行。
  • 方案 2：阿基米德螺旋——一定能碰到，但最坏距离很大。
  • 方案 3：先直行 1km，再沿半径 1 的圆转圈——最坏航程 1 + 23π ≈ 5.712。

核心误解拆解

常见直觉：既然海岸线是单位圆的切线，那我走遍单位圆所有切点（即沿圆周走一圈）不就碰到每条切线了？

关键错觉：路径经过切点 ≠ 路径只能在切点与切线相交。切线是无限长直线，除切点外还延伸到圆外大片区域——你完全不必跑到切点本身，可以在圆外某点更早撞上这条直线。

这就是最优策略的核心：一边旋转一边缓慢向外扩张（r(θ) > 1），让那些本来需要绕很远才碰到的切线被提前拦截，牺牲部分方向的最短航程来压缩最坏情形。

理论结果

  • 严格下界：任何可行路径的最坏航程 ≥ 约 4.603
  • 已知最好构造：数值近似达到约 4.605，非常贴近下界
  • 重要事实：至今没有解析闭式最优解，也没有严格证明 4.605 的路径就是全局最优——这是一个未完全解决的公开数学问题

对比：简单圆策略 ≈ 5.712，"先走 a 再绕单位圆"策略族内最优 ≈ 5.09，都远差于 4.605。

数学建模与变分法

用极坐标 (r(θ), θ) 参数化路径。路径从原点 (r=0) 出发，目标是与所有角度 θ 处的切线相交。角度 θ 处的切线方程为 x cos θ + y sin θ = 1（切点在 (cos θ, sin θ)）。

路径与这条切线相交的条件是：存在某点 (r(φ), φ) 满足 r(φ) cos(φ−θ) = 1，即 r(φ) ≥ 1/cos(φ−θ)。最坏航程 L 是所有切线对应的路径长度的最大值。

最优路径满足变分方程（Euler-Lagrange 方程），这是一个复杂的微分方程，没有解析解。数值求解表明最优路径由若干段组成：初始直线段 + 多段螺旋 + 最终圆弧段。

螺旋路径的具体形式

数值最优解的近似形式是一种"广义螺旋"，极径 r 随角度 θ 的变化满足：

dr/dθ = √(r² − 1) · f(θ)

其中 f(θ) 是一个由变分条件确定的函数。直观理解：路径在角度方向走得越远，径向扩张越快——这样可以在"侧面"拦截那些即将经过的切线，而不必等到正面对上。

最优路径大约旋转 1.5~2 圈，最大径向距离约 2.5~3 个单位。相比之下，简单的"走1单位+绕圆"方案只旋转 2π/3 弧度（120°）。

极小极大的必要条件

最优路径的一个关键性质是均衡性：多条不同角度的海岸线必须同时达到相同的最坏航程 L。如果只有一条海岸线最坏，我们可以微调路径（比如在该方向稍微缩短）来降低 L，而不影响其他方向。因此最优解必然是"多方向同时最坏"的均衡点。

这类似博弈论中的纳什均衡：路径选择者要最小化 L，"自然"（选择最坏海岸线）要最大化 L，最优解是这个零和博弈的鞍点。

数值方法

由于没有解析解，研究者使用数值方法逼近最优路径：

  • 变分法 + 打靶法：建立 Euler-Lagrange 方程，用数值ODE求解器打靶
  • 参数化优化：将路径参数化为有限维向量（如控制点序列），用非线性优化求解
  • 遗传算法/模拟退火：全局搜索，避免陷入局部最优

目前最好的数值结果约 4.605，与下界 4.603 相差不到 0.05%，但无法证明这就是全局最优。

推广与变体

  • 多维版本：在 n 维空间中找超平面，类似但更复杂
  • 已知距离分布：如果知道到岸距离的概率分布，可以求期望航程最小的路径
  • 带速度限制：船速有限时，需要考虑风速、洋流等因素
  • 离散版本：海岸线只有有限条可能方向时，问题简化为有限搜索

近缘问题（容易混淆）

  • Zalgaller 问题：人在宽为 2 的带状森林中，不知方位，求保证逃出的最坏路程——此问题有严格解析最优解（Zalgaller 1961），路径为直线段+圆弧拼接。
  • 雾中船是半平面已知到边界距离=1 的情形，至今无解析最优。两者常被混淆。
Bellman 失海问题（1963 提出）是搜索几何中的经典开放问题。最反直觉之处在于：目标不是"访问所有切点"，而是"与每条切线相交于任意点"——向外扩张能更早拦截某些切线。极小极大的必要条件是多条不同海岸线同时达到同一最大路程 L（若只有一条岸最坏，还可微调路径压低它）。该问题没有初等闭式解，只能数值求解变分法方程组。
003 几何 / 博弈 湖心逃生问题（追击者速度 4 倍）

圆形湖泊，半径 R。游泳者在湖中心，速度 v；追击者在湖岸圆周奔跑，速度 4v。双方都使用最优策略：追击者尽力拦截，游泳者尽力上岸不被抓到。游泳者能否逃脱？

临界半径

设存在一个小圆，半径 r = R/4。游泳者在半径 r 的内圆里，角速度比追击者更快：

  • 游泳者最大角速度 = v/r = 4v/R
  • 追击者角速度 = 4v/R

当游泳者距离湖心 < R/4 时，他转圈调整方位的角速度 > 岸上追击者，可以不断转圈，直到自己和追击者刚好分居圆心两侧（圆心在两人中间，三点共线）。

一旦走到 r = R/4，游泳者的角速度就追不上岸上的人，没法再调整相对角度。

完整逃生步骤

  1. 阶段 1：内圆机动——从圆心出发，在半径略小于 R/4 的小圆内转圈调整角度，达成状态：湖心 O、游泳者 S、追击者 P 三点共线，且 O 在 S、P 中间（S—O—P）。
  2. 阶段 2：直线冲刺——达成对位后，立刻沿着远离追击者的直线径直向岸边游去。

时间对比

此时游泳者到岸边距离 = R − R/4 = 3R/4，上岸耗时 = 3R/(4v)。

追击者需要沿湖岸跑半圈才能堵截，路程 = πR，耗时 = πR/(4v) ≈ 3.14R/(4v)。

因为 3 < π，所以游泳者上岸时间更短，成功逃脱！

临界阈值

追击者速度倍数 k 的临界值为 1 + π ≈ 4.14。当 k < 1+π 时游泳者可逃，k ≥ 1+π 时无法逃脱。题目中 k=4 < 4.14，故可逃。

核心要点
  1. 临界半径 r = R/4：内圈角速度占优，外圈不行
  2. 策略：内圈调整对位 → 直线冲刺
  3. 逃脱条件：3R/(4v) < πR/(4v)，即 3 < π
  4. 速度比临界值：1 + π ≈ 4.14
004 组合 / 递推 灯的翻转操作次数问题

有 2N−1 盏灯排成一排，初始只有第 N 盏亮着，其余全灭。定义一次操作为：选取一段长度 ≥ 3 的连续灯，满足两端灭、中间全亮，将整段灯状态翻转。问进行多少次操作后无法继续操作？

结论

无论操作顺序如何，最终都会在进行 2N−1 − 1 次操作后无法继续。

小规模验证

  • N=2：3 盏灯，初始 `灭、亮、灭`。翻转后 `亮、灭、亮`，灭灯连续，无法继续。总次数 1 = 21−1。
  • N=3：5 盏灯，初始 `灭、灭、亮、灭、灭`。翻转中间 3 盏 → `灭、亮、灭、亮、灭` → 翻转左侧 3 盏 → `亮、灭、亮、亮、灭` → 翻转区间 2-5 → `亮、亮、灭、灭、亮`。总次数 3 = 22−1。
  • N=4：7 盏灯，总次数 7 = 23−1。

递推关系与归纳证明

观察小规模结果，满足递推关系：

T(N) = 2T(N−1) + 1，  T(2) = 1

第一步必须翻转中间 3 盏灯，将原问题拆分为左右两个对称的 N−1 规模子问题。左右两个子问题各需 T(N−1) 次操作，加上初始的 1 次中间操作，总次数满足上述递推式。

求解递推式：T(N) = 2N−1 − 1。

无法操作的条件

无法操作的充要条件：所有灭灯连成连续的一段（不存在两个灭灯被亮灯隔开，否则这两个灭灯即可作为操作区间的两端）。

核心要点
  1. 答案：2N−1 − 1 次，与操作顺序无关
  2. 递推：T(N) = 2T(N−1) + 1，T(2)=1
  3. 关键：翻转中间 3 盏将问题拆为两个 N−1 子问题
  4. 终态：所有灭灯连成连续一段

001 数论 / 丢番图方程 丢番图方程求解技巧：互素乘积为平方数

求解形如"某些因子的乘积为完全平方数"的丢番图方程时，核心技巧是互素分解：若两个互素正整数的乘积是完全平方数，则每个数本身必为完全平方数。这是因为互素意味着它们没有公共素因子，所以平方性必须分别由各自承担。

标准流程

  1. 因式分解：将方程左边分解为若干因子的乘积
  2. gcd 分析：计算各因子的最大公约数，若不互素则除以公共因子使其互素
  3. 平方数条件：互素因子乘积为平方数 ⟹ 每个因子都是平方数，列出子方程
  4. 化简求解：解子方程，通常会转化为佩尔方程或四次方程

典型案例

考虑方程 x(x+1)(x+2)… = y²。设 a, b 为互素正整数且 ab 为平方数，则 a = m², b = n²。若 a, b 不互素，设 d = gcd(a,b)，令 a = da', b = db'，则 gcd(a', b')=1，ab = d²a'b' 为平方数 ⟹ a'b' 为平方数 ⟹ a', b' 各自为平方数。

与佩尔方程的联系

子方程化简后常出现 负佩尔方程 x² − Dy² = −1。其所有正整数解由基本解 (x₁, y₁) 生成：xn + yn√D = (x₁ + y₁√D)2n+1。解序列满足线性递推关系。对于更大的解，可用模运算（模 8、模 5、模 16 等）排除不可能的情况。

核心要点
  1. 互素数乘积为平方数 ⟹ 每个数都是平方数
  2. 不互素时先除以 gcd，转化为互素情形
  3. 子方程常化为佩尔方程，用模运算排除大解
  4. 这是处理"乘积=幂"型丢番图方程的通用套路
002 分析 / 渐近分析 幂级数系数渐近：达布定理与伯努利数

求幂级数 f(z) = Σ anzn 的系数 an 的渐近行为时，达布（Darboux）渐近定理是核心工具：系数的主项由收敛圆周上离原点最近的奇点决定。

达布渐近定理

若 f(z) 在收敛圆周 |z|=R 上只有有限个奇点，且均为一阶极点，留数为 cj，则系数的渐近主项为各极点贡献之和：

an ~ ∑j cj · zj−n−1

其中 zj 是奇点位置，cj 是留数。更远的奇点贡献是高阶小量，可忽略。

案例：tan z 的展开系数

tan z 是奇函数，麦克劳林展开仅含奇次幂：tan z = Σ Tn z2n−1。

奇点满足 cos z = 0，即 z = ±π/2, ±3π/2, …。离原点最近的奇点为 ±π/2，模长为 π/2，均为一阶极点。

在 z = π/2 处，留数 = lim(z−π/2)·tan z = −1（由洛必达法则）。同理 z = −π/2 处留数也为 −1。

两个最近奇点的贡献相加，得到系数主项。更远的奇点 ±3π/2 对应贡献阶为 (2/(3π))n，底数远小于 2/π，当 n → ∞ 时是主项的高阶小量。

与伯努利数的联系

tan z 的展开式可由伯努利数表示：

tan z = ∑n≥1 22n(22n−1)|B2n|(2n)! z2n−1

由伯努利数的渐近公式 |B2n| ~ 2(2n)!/(2π)2n，代入即可得到与达布定理一致的系数渐近行为。两种方法殊途同归。

核心要点
  1. 达布定理：系数主项由最近奇点的留数决定
  2. 一阶极点 z₀（留数 c）贡献 c · z₀−n−1
  3. tan z 的最近奇点 ±π/2，系数 ~ (2/π)2n+1
  4. 可用伯努利数渐近公式交叉验证
003 数论 / 构造性证明 奇怪的数：构造性证明无限性

"奇怪的数"问题：是否存在无限多个正整数 n，使得可以找到五个两两不同的大于 1 的正整数，满足某些等式关系？答案是存在无限个，通过构造性证明。

构造性证明思路

对任意偶数 k ≥ 4，构造五个数。核心技巧是利用偶数的性质：

  1. 构造前两个等式：令 a, b 为关于 k 的表达式，使它们在代入不同变量时给出相等的值，且 a, b, k 两两不同
  2. 构造第三个等式：令 c 为另一表达式。由于 k 是偶数，c 也是偶数，故 c 必为 4 的倍数。令 c = 4d，则 d 为大于 1 的正整数
  3. 验证两两不同：五个数严格递增，故两两不同且均大于 1
  4. 无限性：可取所有 ≥ 4 的偶数（共无限多个），每个对应唯一的严格递增五元组

方法的通用性

这类"证明存在无限多个满足某性质的数"的问题，构造性证明是最直接的方法：只要能找到一个含自由参数的构造，使得参数取无限多个值时都满足条件，就证明了无限性。

常见构造策略：

  • 利用奇偶性构造（如本题用偶数保证 4 的倍数）
  • 利用多项式恒等式构造
  • 利用递推序列构造
  • 利用中国剩余定理构造
核心要点
  1. 证明无限性的构造性方法：找含自由参数的构造
  2. 利用偶数性质保证整除性（4 的倍数）
  3. 验证两两不同：严格递增即可
  4. 通用性：奇偶性、多项式恒等式、递推、CRT 都是常用构造工具
