001 · 数论 / 分析 十进制正规数

一个实数的小数无限展开中，任意 k 位数字串出现的极限概率均等，即所有 10k 种等长串以相同频率出现，称该数为十进制正规数。

严格定义：设实数 x ∈ (0, 1) 的十进制小数展开为 x = 0.a1a2a3…an…，对任意长度 k ≥ 1，任意长度为 k 的数字串 s ∈ {0, …, 9}k，记 Ns(n) 为前 n 位中 s 出现的次数。若

limn→∞ Ns(n)n = 110k

对一切 s 成立，则称 x 为十进制正规数。同理可定义 b 进制正规数。

正规数的构造性结果

科普兰-厄尔多斯常数

全体素数拼接：0.2357111317192329… 是十进制正规数。任意进制同理。

达文波特-厄尔多斯多项式族

任取非常数整系数多项式 f(n)（f(n)→+∞），则 0.f(1)f(2)f(3)… 是正规数。如 f(n)=n, n2, 2n+1。

Stoneham 常数族

αb,c = ∞∑k=1 1ck · bck

在 b 进制下正规，但在 bc 进制下不正规——正规性是依赖于进制的性质。

几乎所有实数都是正规数（测度为 1），但具体证明某个常见常数（如 π、√2、e）是正规数却极其困难——至今无人能证。几乎所有数都满足，但你一个也举不出来。能构造出的正规数不多，大多"人为拼出来"。Stoneham 常数揭示了进制依赖性：一个数可以在二进制下正规，在六进制下却不正规。
002 · 数论 / 组合 斐波那契进制与泽肯多夫定理

斐波那契进制（泽肯多夫表示）

以斐波那契数列为位权的记数系统。约定 F1 = 1，F2 = 2，F3 = 3，F4 = 5，F5 = 8…… 任意正整数 N 可写作：

N = ∑k dk Fk，其中 dk ∈ {0, 1}

且不允许出现连续的 1。例如 10101Fib = F5 + F3 + F1 = 8 + 3 + 1 = 12。进位规则：011Fib → 100Fib。

泽肯多夫定理

定理：任一正整数可唯一表示为若干个不相邻的斐波那契数之和。

存在性（归纳法）：取满足 Fm ≤ n < Fm+1 的最大下标 m，记 r = n − Fm。则 r < Fm−1，由归纳假设 r 有合法表示且最大项 < Fm−1，不与 Fm 相邻。

唯一性：设两种表示最大下标不同，不含 Fm 的一边最大值为 Fm−1 + Fm−3 + … < Fm（隔项和严格小于下一项），矛盾。

二进制的唯一性几乎显然（每位取 0 或 1），但斐波那契进制加上"不相邻"约束后唯一性反而需要证明——证明本身揭示了斐波那契数列"隔项和小于下一项"这个优雅性质。长度为 n 的 0/1 串中不出现相邻 1 的方案数恰好是斐波那契数，这正是该进制的计数基础。
003 · 分析 / 复变 朗伯 W 函数

朗伯 W 函数 W(z) 是 f(w) = w·ew 的反函数：x·ex = t ⟺ x = W(t)。分为两支：

  • 主分支 W0(z)：定义域 z ≥ −1e ≈ −0.36
  • 负分支 W₋1(z)：定义域 −1e ≤ z < 0

两支在 z = −1e 处汇合：W0(−1e) = W₋1(−1e) = −1。

基本性质

  • W(z) ~ ln z − ln ln z，当 z → +∞
  • 导数：W'(z) = W(z)z(1 + W(z))，W'(0) = 1
  • 泰勒展开：W0(z) = ∞∑n=1 (−n)n−1n! zn，|z| < 1e

Ω 常数

Ω = W0(1) ≈ 0.567，满足 e−Ω = Ω。Ω 是超越数。其他数值：W0(2) ≈ 0.853，W0(3) ≈ 1.05。

初次遇到 x·ex = t 或 x + ln x = t 时，W 函数就像"开方"——它不是初等函数，但一旦认识了它，一大类超越方程就有了"闭式解"。
004 · 分析 / 超运算 迭代幂运算（Tetration）与幂塔导数

加法是重复计数，乘法是重复加法，幂运算是重复乘法——那么"重复幂运算"是什么？这就是迭代幂运算（Tetration），也叫幂塔、超-4 运算。

定义 yn = nx = x ↑↑ n，即 n 个 x 从右往左嵌套取幂：

y0 = 1，  y1 = x，  yn = xyn−1

例如 y2 = xx，y3 = xxx，y4 = xxxx。注意幂运算不满足结合律，必须从最顶层（最右边）开始算。

与初等运算的层级关系
  1. 加法（超-1）：a + b = 重复计数 b 次
  2. 乘法（超-2）：a × b = 重复加 b 次
  3. 幂运算（超-3）：ab = 重复乘 b 次
  4. 迭代幂（超-4）：ba = 重复取幂 b 次
  5. 更高层：Pentation（超-5）、Hexation（超-6）……存在但极少使用

幂塔的导数公式

对 yn = x ↑↑ n 求导。由 yn = xyn−1 = eyn−1·ln x，用链式法则：

yn' = yn · ( yn−1' · ln x + yn−1x )

这是一个递推式。反复代入展开，可得显式求和公式：

yn' = 1x · n−1∑k=0 ( yn · yn−1 · … · yn−k ) · (ln x)k

即每一项是"从 yn 起连续 k+1 层的乘积"乘以 (ln x)k，再除以 x。

验证：前几层

  • n=1：y1 = x，y1' = 1。公式给出 1x·y1·(ln x)0 = 1x·x = 1 ✓
  • n=2：y2 = xx。直接求导 y2' = xx(ln x + 1)。公式给出 1x[y2·y1 + y2·y1·y0·ln x] = 1x[y2·x + y2·x·1·ln x] = y2(1 + ln x) ✓
  • n=3：y3 = xxx，y3' = y3·y2x · (1 + x·ln x + x·ln2x) ✓
幂塔增长极为迅猛：42 = 65536，52 已是天文数字。这也是迭代幂在实际计算中极少超过 4~5 层的原因

无穷幂塔与朗伯 W 函数

当层数趋于无穷时，幂塔 h(x) = xxx⋯ 满足不动点方程 h = xh。两边取对数：ln h = h ln x，即 (−h ln x)·e−h ln x = −ln x。用 W 函数解得：

h(x) = W(−ln x)−ln x

收敛域：无穷幂塔仅在 e−e ≈ 0.066 ≤ x ≤ e1e ≈ 1.444 时收敛。x = e1e 时 h = e；x = e−e 时 h = 1e。

特殊值

  • 0x = 1（空积约定，类似 x0 = 1）
  • 1x = x，2x = xx，3x = xxx
  • n1 = 1（任何层数，1 的任何次幂都是 1）
  • n2：1, 2, 4, 16, 65536, 265536, … 增长极其恐怖
迭代幂运算展示了"运算层级"的威力：每升一级，增长速度发生质变。幂塔的导数公式揭示了一个优雅结构——每层的贡献是"前面所有层的乘积"乘以 (ln x) 的幂次。无穷幂塔恰好是朗伯 W 函数的一个应用，收敛域 e−e ≤ x ≤ e1/e 是一个经典且反直觉的结果——x 不能太大也不能太小。
004 · 分形几何 自相似图形的豪斯多夫维数

一条线段有 1 维，一个正方形有 2 维——这是直觉。但如果一个图形"比线粗一点，又比面薄一点"，它该有几维？分形几何给出了答案：维数可以是分数。

对严格自相似的分形图形，若整体放大 k 倍后可拆成 N 个与原集合全等的子集，则豪斯多夫维数：

d = ln Nln k
康托尔集每次挖去中间 1/3；科赫曲线每次将线段三等分、中间段替换为等边三角形的两边

经典例子

图形N（子集数）k（放大倍数）维数 d
线段221
正方形422
康托尔三分集23ln2/ln3 ≈ 0.631
科赫雪花43ln4/ln3 ≈ 1.262
谢尔宾斯基三角形32ln3/ln2 ≈ 1.585
分形维数可以不是整数——这正是"分形"名字的来源（fractal = fractional dimension）。科赫雪花的长度无限但面积有限，维数介于 1 和 2 之间。直觉上：康托尔集"比点多、比线少"，所以维数在 0 和 1 之间；科赫曲线"比线复杂、比面简单"，维数在 1 和 2 之间。
005 · 组合数学 有序整数分拆（Composition）

将正整数 n 拆为若干正整数的和，顺序不同视为不同分拆。记 an 为总数。

① 用 1 ~ m 分拆

  • n ≤ m：an = an−1 + … + a1 + 1
  • n > m：an = an−1 + … + an−m

m = 2 时退化为斐波那契递推。隔板法直接给出无限制时共 2n−1 种。

② 通项（特征方程法）

以 m=2 为例：λ2 = λ + 1，解得 λ1 = (1+√5)/2, λ2 = (1−√5)/2，

an = 1√5 · [ 1 + √52n+1 − 1 − √52n+1 ]
递推法和特征方程法给出了更一般的框架——当各部分大小有限制时，这套方法依然适用。
006 · 数论 / 分析 伯努利数与欧拉-麦克劳林公式

伯努利数

通过生成函数定义：

xex − 1 = ∞∑n=0 Bnn! xn

前几个值：B0 = 1，B1 = −12，B2 = 16，B3 = 0，B4 = −130，B5 = 0，B6 = 142，…

重要性质：除 B1 外，所有奇数下标伯努利数为 0（B2n+1 = 0, n ≥ 1）。

递推公式

Bn = −1n+1 · n−1∑k=0 n+1k · Bk

冯·施陶特-克劳森定理

B2n 的分母恰好是所有满足 p−1 | 2n 的素数 p 的乘积：

denom(B2n) = ∏p−1 | 2n p

例如：denom(B2) = 6，denom(B4) = 30，denom(B6) = 42，denom(B12) = 2730。

欧拉-麦克劳林公式

连接离散求和与连续积分的桥梁：

b∑k=a f(k) = b∫a f(x) dx + f(a) + f(b)2 + m∑j=1 B2j(2j)! · [f(2j−1)(b) − f(2j−1)(a)] + Rm

经典应用

  • 调和级数：Hn = ln n + γ + 12n − 112n2 + …
  • 斯特林公式：ln n! ≈ n ln n − n + ln(2πn)2 + 112n − …
  • ζ(2n) = (−1)n+1 B2n (2π)2n2·(2n)!
伯努利数把幂和求和、欧拉-麦克劳林公式、黎曼 zeta 函数偶数值、费马大定理的正则素数等看似无关的领域串联在一起。分母的素数结构是数论中非常漂亮的结果。欧拉-麦克劳林公式是"求和 ≈ 积分 + 修正项"的精确化，修正项系数恰好是伯努利数——这也是伯努利数出现在那么多看似不相关公式里的原因。
007 · 分析 / 特殊函数 Beta 函数、Gamma 函数与华里士公式

Gamma 函数

Γ(z) = ∫0+∞ tz−1 e−t dt   (Re z > 0)
  • 递推：Γ(z+1) = z Γ(z)；正整数：Γ(n+1) = n!
  • 特殊值：Γ(12) = √π

Beta 函数

B(p, q) = 1∫0 tp−1(1−t)q−1 dt = Γ(p) Γ(q)Γ(p+q)

与组合数的联系：B(k+1, n−k+1) = 1(n+1) nk。

三角函数积分的一般公式（华里士公式的推广）：

π/2∫0 sinmx cosnx dx = 12 · Γ(m+12) Γ(n+12)Γ(m+n+22)

余元公式（Euler 反射公式）

Γ(z) Γ(1−z) = πsin(π z)

令 z = 12 即得 Γ(12) = √π。揭示了 Gamma 函数与三角函数的深刻联系。

勒让德加倍公式

Γ(2z) = 22z−1√π · Γ(z) · Γ(z + 12)

华里士公式（Wallis 公式）

记 In = ∫0π/2 sinnx dx，分部积分得递推：

I2k = π2 · (2k−1)!!(2k)!!，  I2k+1 = (2k)!!(2k+1)!!

华里士乘积

π2 = ∞∏n=1 2n2n−1 · 2n2n+1

历史上第一个把 π 表示为有理数无穷乘积的公式。核心技巧：夹逼 sin2k+1x ≤ sin2kx ≤ sin2k−1x 积分后取极限。

斯特林公式（渐近展开）

Γ(z+1) ≈ zz e−z √(2π z)

正整数时即 n! ≈ nn e−n √(2π n)。华里士乘积可由此导出，反之华里士公式也可确定斯特林公式中的系数 √(2π)。

这几个公式构成了一个紧密网络：余元公式连接三角/复分析，加倍公式展示缩放性质，华里士公式把 π 表示为有理数无穷乘积，斯特林公式描述无穷远行为。Gamma 函数把"阶乘"从整数推广到全体实数，Beta 函数则是桥梁——许多含三角函数、幂函数的积分都能通过换元变成 Beta 积分再求值。
008 · 数论 / 趣味常数 几个有趣的常数

① 布伦常数（Brun's constant）

所有孪生素数对的倒数之和：B2 = (13+15) + (15+17) + (111+113) + … ≈ 1.902160583。有限值——布伦筛法证明了收敛性。而全体素数倒数和是发散的。

② 杜芬数（Dottie number）

cos x = x 的唯一实根：D ≈ 0.7390851332。超越数。从任意实数出发反复取余弦最终都收敛到此数——不动点定理的直观例子。

③ 康威常数（Conway's constant）

外观数列 1, 11, 21, 1211, 111221, 312211, … 长度之比极限 λ ≈ 1.303577269，是某 71 次多项式的唯一正实根。任何以非 22 结尾的数字串作为起点，增长速度都由同一个 λ 控制。

三个常数代表三种风味：布伦常数是"稀少但存在"；杜芬数是极简的超越数例子；康威常数展示"从简单规则中涌现出复杂代数结构"。
009 · 线性代数 / 三维几何 欧拉角与罗德里格斯旋转公式

欧拉角是三维旋转群 SO(3) 的三参数参数化，用三次依次执行的旋转描述刚体姿态。想象一架飞机：先绕垂直轴偏航（yaw），再绕水平轴俯仰（pitch），最后绕纵轴滚转（roll）——这三个角度就是一组欧拉角。

欧拉角用三次绕轴旋转描述姿态。航空中常用 Z-Y-X 顺序：先偏航（z）、再俯仰（y）、最后滚转（x）

单轴旋转矩阵（右手坐标系，逆时针为正）

Rx(θ) = 1000cosθ−sinθ0sinθcosθ
Ry(θ) = cosθ0sinθ010−sinθ0cosθ
Rz(θ) = cosθ−sinθ0sinθcosθ0001

矩阵乘法规则：先作用放右侧，后作用放左侧（R = RB·RA）。

外在旋转 vs 内在旋转

  • 外在（静态）：三次旋转绕固定世界轴。R外 = RC(γ)·RB(β)·RA(α)
  • 内在（动态）：每次绕物体当前自身轴。R内 = RA(α)·RB(β)·RC(γ)。工程中最常用。

内在-外在等价定理

定理：按顺序 X1→X2→X3 的内在旋转 ≡ 按顺序 X3→X2→X1 的外在旋转，角度数值相等。

证明（两步情形，三步同理）：要证 内在 A→B = 外在 B→A。第一步绕自身 A 轴转 α，初始时自身 A 轴与世界 A 轴重合，矩阵 RA(α)。第二步绕旋转后的自身 B 轴转 β，用共轭变换：R绕自身B轴 = RA(α)·RB(β)·RA(α)−1。总矩阵 R内 = RA(α)·RB(β) = R外。证毕。

经典欧拉角 vs 泰特-布莱恩角

合法旋转顺序共 3×2×2 = 12 种，分两大类：

  • 经典欧拉角（6 种）：首尾同轴（Z-X-Z, Z-Y-Z, X-Y-X, X-Z-X, Y-X-Y, Y-Z-Y）。角度命名：进动/章动/自转。奇点：中间角 = 0° 或 180°
  • 泰特-布莱恩角（6 种）：三轴全不同（Z-Y-X, Z-X-Y, X-Y-Z, X-Z-Y, Y-X-Z, Y-Z-X）。角度命名：偏航/俯仰/滚转。奇点：中间角 = ±90°

Z-Y-X 内在旋转（航空标准）的前向向量：f = (cosα·cosβ, sinα·cosβ, −sinβ)T。

万向锁（Gimbal Lock）

中间角取到奇点值时，自由度从 3 退化为 2。

  • 数学本质：雅可比矩阵秩亏
  • 拓扑本质：SO(3) ≅ RP3，由毛球定理，不存在全局光滑的三参数参数化——任何用三个实数表示三维旋转的方式都必然有奇点
  • 规避：避开奇点区域，或改用四元数（SLERP 插值）

罗德里格斯旋转公式

由奥林德·罗德里格斯 1840 年提出。设旋转轴为单位向量 k，向量 v 绕 k 按右手定则逆时针旋转 θ：

v' = v cosθ + (k × v) sinθ + k (k·v)(1 − cosθ)

三项几何意义

  • v cosθ：垂直于轴的平面上的投影缩放
  • (k × v) sinθ：切向分量，实现"转向"
  • k(k·v)(1−cosθ)：平行于轴的分量修正，沿轴方向不变

垂直轴简化

k·v = 0 时第三项消失：v' = v cosθ + (k × v) sinθ。旋转完全在垂直平面内，与二维旋转一致。

坐标展开（轴 k = (−yr, xr, 0)，r = √(x2+y2)）：

x' = x cosθ + xzr sinθ，  y' = y cosθ + yzr sinθ，  z' = z cosθ − r sinθ

优势

  • 通用：适用于任意过原点旋转轴
  • 无分支：只有叉乘、点积、线性组合
  • 数值稳定：累计误差小
共轭变换是群论的核心技巧：绕"歪掉的轴"旋转 = 先转回标准位置 → 绕标准轴旋转 → 再转回去。不同行业对坐标轴和旋转顺序的约定差异极大（航空航天用 Z-Y-X 内在，Unity 用 Z-X-Y 左手系，ROS 用 X-Y-Z 外在），使用前务必确认约定。欧拉角与罗德里格斯公式是两种互补工具：欧拉角三角度参数化，直观但有奇点；罗德里格斯"轴+角"参数化，无奇点但参数冗余（轴有正负二义性）。
010 · 抽象代数 赋范可除代数与维数定理

"n 维数系" = 实数域上的 n 维代数。要成为"好用的数系"，通常要求：有单位元 1、可除性（非零元有唯一逆元）、赋范性（|ab| = |a|·|b|）、（可选）交换律/结合律。保留性质越多，维数限制越严格。

为什么不存在三元数

用三次单位根构造三元数会产生零因子（两非零数相乘为 0），可除性失效。更深层：实系数奇次多项式必有实根，构造的代数天然可拆分。

弗罗贝尼乌斯定理

定理：实数域上有限维、结合、可除的代数只有 3 种——实数 ℝ（1 维）、复数 ℂ（2 维）、四元数 ℍ（4 维）。三维结合可除代数不存在。

赫尔维茨定理（Hurwitz 定理）

定理：实数域上有限维、赋范、交错的代数，维数只能是 1、2、4、8。

交错律：对任意 a, b，(aa)b = a(ab) 且 (ba)a = b(aa)——比结合律弱，但足以保证无零因子。

维数数系交换结合可除
1实数 ℝ✓✓✓
2复数 ℂ✓✓✓
4四元数 ℍ✗✓✓
8八元数 𝕆✗✗（交错）✓

16 维十六元数也存在，但连交错律都不满足，有大量零因子，已不具备"数系"的核心意义。

左正则表示

对 n 维数系中每个数 a，"左乘"操作 La(b) = a·b 是 n 维线性变换，可用 n×n 矩阵表示。数与矩阵一一对应，信息量等价——但全体矩阵比数系大得多，只有一小类特殊矩阵才对应数系元素。例如复数 a+bi 对应矩阵 a−bba，只是所有 2×2 矩阵中"旋转+等比缩放"那一小类。

赫尔维茨定理给出了"好用的数系"维数的完整答案：1、2、4、8，一个都不能多。这和 Bott 周期定理、除法代数的存在性紧密相关——1、2、4、8 这几个数在拓扑学中反复出现，背后是同一个深刻的数学结构。弗罗贝尼乌斯定理是赫尔维茨定理在"保留结合律"约束下的特例。
011 · 高维几何 正多胞体与高维欧拉公式

正多胞体（Regular Polytopes）

二维有无穷多种正多边形，三维只有 5 种柏拉图立体——那么更高维呢？直觉上"维度越高约束越强，种类应该越少"，但实际规律出人意料：

维度 n正多胞体数量名称
2∞正多边形（正三角形、正方形、正五边形……）
35正四面体、正六面体、正八面体、正十二面体、正二十面体
46正五胞体、正八胞体(超立方体)、正十六胞体、正二十四胞体、正一百二十胞体、正六百胞体
≥ 53正单纯形、正超立方体、正正轴形（对应三维的正四面体、正方体、正八面体）

数量从二维无穷 → 三维 5 → 四维 6（反弹！） → 五维及以上 3（收敛稳定）。四维反而比三维多 1 种，并非"维度越高数量越少"的单调趋势。

核心洞察

任意维度都能构造出 3 种"基础型"（单纯形、超立方体、正轴形），它们的对称性最简洁普适。正十二面体、正二十面体、四维正二十四胞体这类"特殊型"只在低维有足够几何空间满足"所有面/胞全等、所有顶点对称"的严格条件。五维以上空间的几何约束强到只容得下 3 种基础型。

高维欧拉公式

经典 V − E + F = 2 在高维凸多胞体上的推广。

定理：对 n 维凸多胞体，设 Nk 为 k 维面数量（k=0 顶点，k=1 棱，k=2 面，…），则：

n−1∑k=0 (−1)k Nk = 1 − (−1)n

特例

  • 三维（n=3）：V − E + F = 2
  • 四维（n=4）：V − E + F − C = 0

右边 1−(−1)n 就是 n 维球的欧拉示性数。凸多胞体与球拓扑等价，故示性数相同。

五维以上几何对称约束强到只容得下 3 种基础型。正十二面体、正二十面体、四维正二十四胞体这类"特殊型"只在低维有足够几何空间满足严格对称条件。欧拉示性数是拓扑不变量——"形状的DNA"，不管怎么揉捏变形（不撕裂不粘合），V−E+F 永远不变。高维欧拉公式把它推广到任意维度，是代数拓扑学的基石之一。

001 · 射影几何 彭赛列闭合定理

定理：给定两条二次曲线 C（外）和 D（内），从 C 上任一点出发，交替作 D 的切线交 C，若某起点经 n 次后回到起点（形成彭赛列 n 边形），则 C 上任意起点都能作出闭合 n 边形。闭合性只由两曲线相对位置决定，与起点无关。

彭赛列 n=3 情形：三角形内接于外圆 C、外切于内圆 D。若存在这样一个三角形，则从 C 上任意点出发都能作出闭合三角形。

特例：双心四边形

1(R−d)2 + 1(R+d)2 = 1r2

其中 R 为外接圆半径，r 为内切圆半径，d 为圆心距。

把"几何闭合"问题转化为纯粹"存在性"问题——只要找到一个闭合的，就有无穷多个。与椭圆光学性质、二次曲线配极理论紧密相关。
002 · 几何 / 积分 霍迪奇定理

定理：取光滑凸闭合曲线 C，定长弦两端贴合 C 滑动一周。弦上定点把弦分为 p、q 两段，该定点划出内曲线 C'。则环形面积恒为：

SC − SC' = πpq

只与弦被分成的两段长度有关，与原曲线形状无关！p = q = L/2 时面积 = πL2/4，恰好等于直径为 L 的圆面积。

霍迪奇定理示意图。定长弦 AB 在凸曲线 C 上滑动，弦上点 P（分弦为 p、q）划出虚线内曲线 C′。环域面积恒为 πpq，与 C 的形状无关。
背后是积分几何中的运动学公式（克罗夫顿公式一族），和曲线整体形状无关。
003 · 数论 伯特兰-切比雪夫定理

定理：对任意 n ∈ ℤ⁺，(n, 2n] 内必存在素数。

应用：n! 不是完全平方数

(n/2, n] 中存在素数 p，在 n! 中只出现一次（2p > n），指数为奇数。也证明了素数无穷（设最大素数 P，取 n = P，则 (P, 2P] 内有新素数，矛盾）。

素数定理告诉我们 (n, 2n] 内素数个数约为 n/ln n。切比雪夫原始证明用 C(2n,n) 的素因子分析。
004 · 数论 勒让德公式与库默尔定理

勒让德公式

vp(n!) = ∞∑k=1 ⌊npk⌋ = n − Sp(n)p − 1

其中 Sp(n) 为 n 在 p 进制下各位数字和。组合数推广：vp(nm) = Sp(m) + Sp(n−m) − Sp(n)p − 1。

库默尔定理

定理：vp(nm) 等于 p 进制下 m + (n−m) = n 时的进位次数。

每进位一次，数字和减少 p−1，对应 vp 增加 1。勒让德公式用数字和，库默尔定理用进位次数，两者完全等价。与卢卡斯定理（005）呼应：mi > ni 说明该位必然进位，vp ≥ 1，即 C(n,m) ≡ 0 mod p。
005 · 数论 / 组合 卢卡斯定理

定理：设 p 为素数，n, m 的 p 进制展开为 n = ∑i nipi，m = ∑i mipi，则

nm ≡ ∏i nimi   (mod p)

若某位 mi > ni，则 nimi = 0，原式模 p 为 0。

和勒让德公式与库默尔定理（004）呼应：mi > ni 说明该位必然进位，vp ≥ 1，即 C(n,m) ≡ 0 mod p。把"大组合数模素数"拆成"小组合数相乘模素数"，竞赛中极其常用。

008 · 组合数学 多项式定理

(a+b)2 = a2+2ab+b2，(a+b+c)2 = a2+b2+c2+2ab+2ac+2bc——那么 (a+b+c+d+…)n 怎么展开？多项式定理给出答案。

(x1 + x2 + … + xm)n = ∑n1+…+nm=n n!n1! n2! … nm! · x1n1 x2n2 … xmnm

求和遍历所有满足 n1+n2+…+nm=n 的非负整数组。系数 n!n1! n2! … nm! 称为多项式系数，记作 nn1, n2, …, nm。

层级关系
  1. 多项式定理（m 个变量）⊃ 三项式定理（m=3）⊃ 二项式定理（m=2）
  2. 系数 = 把 n 个不同位置分成大小为 n1,…,nm 的 m 组的方案数
  3. 系数和 = mn（令所有变量取 1）

特例

  • m=2（二项式定理）：系数 nk, n−k = nk
  • m=3（三项式定理）：(x+y+z)n = ∑a+b+c=n n!a! b! c! xaybzc

完整展开示例（视觉震撼）

把公式全部写开，能直观感受项数爆炸。(a+b+c)4 共 15 项：

(a+b+c)4 = a4 + b4 + c4
  + 4(a3b + a3c + ab3 + b3c + ac3 + bc3)
  + 6(a2b2 + a2c2 + b2c2)
  + 12(a2bc + ab2c + abc2)

再看 (a+b+c+d)4，变量只多一个，项数暴增到 35 项：

(a+b+c+d)4 = a4 + b4 + c4 + d4
  + 4(a3b + a3c + a3d + ab3 + b3c + b3d + ac3 + bc3 + c3d + ad3 + bd3 + cd3)
  + 6(a2b2 + a2c2 + a2d2 + b2c2 + b2d2 + c2d2)
  + 12(a2bc + a2bd + a2cd + ab2c + ab2d + b2cd + abc2 + ac2d + bc2d + abd2 + acd2 + bcd2)
项数增长规律
  1. (a+b)4：5 项（二项式）
  2. (a+b+c)4：15 项（三项式）
  3. (a+b+c+d)4：35 项（四项式）
  4. (a+b+c+d+e)4：70 项（五项式）
  5. 通项：(x1+…+xm)n 的项数 = n+m−1m−1（隔板法）

组合意义

把 n 个因式相乘，每个因式选一个变量。要得到 x1n1x2n2…xmnm，相当于把 n 个位置分成大小为 n1, n2, …, nm 的 m 组——等价于多重集合 {n1·x1, n2·x2, …, nm·xm} 的全排列数。

系数和

令全部变量取 1：

∑n1+…+nm=n nn1, n2, …, nm = mn

m=2 时即二项式系数和 2n。

带系数的展开

若括号内带系数，如 (2a − b + 3c)5 中 a2b2c1 的系数：

52, 2, 1 · 22 · (−1)2 · 31 = 5!2! 2! 1! · 4 · 1 · 3 = 360

推导思路

把前 m−1 个变量打包：[(x1+…+xm−1) + xm]n，先用二项式定理展开，再对 (x1+…+xm−1)n−nm 递归套用多项式定理——本质上是反复使用二项式定理。

多项式定理是二项式、三项式的终极推广。多项式系数在组合数学、概率论（多项分布）、统计力学中频繁出现。与"有序整数分拆"不同：多项式系数是把 n 个不同位置分成指定大小的组，而 composition 是把 n 拆成有序的正整数之和。

001 · 渐近分析 / 组合 中文读数长度的渐近行为

"100" 读作"一百"（2 字），"999" 读作"九百九十九"（5 字），"100000000" 读作"一亿"（2 字）……数越大读的字越多，但多多少？和数的大小是什么关系？

设 f(N) 为正整数 N 用中文普通话读出的汉字个数（不含"零"）。考察 f(N) 与 ln N 的比值极限。

中文读数规则

  • 数字字符：零一二三四五六七八九，各占 1 字
  • 数位单位：十、百、千，各占 1 字
  • 四位分节大单位：万(104)、亿(108)、兆(1012)……每 4k 位一个，各占 1 字

渐近尺度

N ≈ 10m ⟹ ln N = m ln 10。中文按 4 位分块，共 ⌈m4⌉ 块。每块最多 4 个数字 + 3 个权（千、百、十）= 7 字，再加块尾大单位 1 字。故每块字数为常数，不随 m 增长：

f(N) = Θ(m4) = Θ(ln Nln 10)

比值 f(N)ln N 是有界量，但普通极限不存在——在两个常数之间震荡。

核心结论
  1. 量级：f(N) ∝ log10 N，即汉字数与十进制位数成正比
  2. 上极限：全为 9 时取得，limsup = 2ln 10 ≈ 0.869
  3. 下极限：1 后全 0 时取得，liminf = 14 ln 10 ≈ 0.109
  4. 结论：比值在 0.109 ~ 0.869 之间震荡，不收敛

上极限（全为 9，如 9999…9999）

N = 104k − 1，即 4k 个 9。每块"九千九百九十九"= 7 字，k 块共 7k 字；块尾单位"万、亿…"共 k−1 个（末尾无单位）。总字数 f ≈ 8k：

limsupN→∞ f(N)ln N = 8k4k ln 10 = 2ln 10 ≈ 0.869

下极限（1 后面全 0，如一亿、一兆）

N = 104k，读作"一兆…亿万"，仅 k+1 字（1 个数字 + k 个大单位）：

liminfN→∞ f(N)ln N = k4k ln 10 = 14 ln 10 ≈ 0.109

含"零"的情形

数字中间出现 0 时插入"零"字，但每块内部最多插 3 个零，每块总字数仍为常数。量级不变，f(N) = O(log N)，上下极限只略增大，仍无单一极限。

与英文对比

英文按 3 位分节（thousand, million, billion…），故 limsup 常数分母为 3 ln 10。中文 4 位分节是根源差异。

这个问题把语言文字规则转化为渐近分析，很适合体会"离散结构的对数尺度"。一个有趣的对照："一亿"只有 2 个字，"99999999"却要读约 16 个字——数差不多大，读法长度差了 8 倍。
002 · 几何 / 搜索论 雾中船问题（Bellman 失海问题）

船距直线海岸线垂直距离 1km，起雾后完全不知道岸的方位。设计一条连续航行路径，保证无论岸是哪条距自己 1 的直线都能碰到，且使最坏情况下的总航程最小（极小极大优化 min-max）。

几何转化

所有可能的海岸线 = 单位圆 r=1 的全部切线。一条直线到原点距离为 1 ⟺ 它是单位圆的切线。路径必须与每条切线在某点相交。目标：

minγ { maxτ [路径 γ 走到与切线 τ 相交的路程] }
虚线圆为单位圆（船到岸距离=1），四条灰线为单位圆的切线（可能的海岸线）。最优路径（红色）是从原点出发、一边旋转一边缓慢向外扩张的螺旋，在圆外拦截切线——而非沿圆周走一圈。

朴素方案

  • 方案 1：朝任一方向直行 1km——若刚好朝岸则 1km 到，最坏方向垂直于岸则永远碰不到，不可行。
  • 方案 2：阿基米德螺旋——一定能碰到，但最坏距离很大。
  • 方案 3：先直行 1km，再沿半径 1 的圆转圈——最坏航程 1 + 23π ≈ 5.712。

核心误解拆解

常见直觉：既然海岸线是单位圆的切线，那我走遍单位圆所有切点（即沿圆周走一圈）不就碰到每条切线了？

关键错觉：路径经过切点 ≠ 路径只能在切点与切线相交。切线是无限长直线，除切点外还延伸到圆外大片区域——你完全不必跑到切点本身，可以在圆外某点更早撞上这条直线。

这就是最优策略的核心：一边旋转一边缓慢向外扩张（r(θ) > 1），让那些本来需要绕很远才碰到的切线被提前拦截，牺牲部分方向的最短航程来压缩最坏情形。

理论结果

  • 严格下界：任何可行路径的最坏航程 ≥ 约 4.603
  • 已知最好构造：数值近似达到约 4.605，非常贴近下界
  • 重要事实：至今没有解析闭式最优解，也没有严格证明 4.605 的路径就是全局最优——这是一个未完全解决的公开数学问题

对比：简单圆策略 ≈ 5.712，"先走 a 再绕单位圆"策略族内最优 ≈ 5.09，都远差于 4.605。

近缘问题（容易混淆）

  • Zalgaller 问题：人在宽为 2 的带状森林中，不知方位，求保证逃出的最坏路程——此问题有严格解析最优解（Zalgaller 1961），路径为直线段+圆弧拼接。
  • 雾中船是半平面已知到边界距离=1 的情形，至今无解析最优。两者常被混淆。
Bellman 失海问题（1963 提出）是搜索几何中的经典开放问题。最反直觉之处在于：目标不是"访问所有切点"，而是"与每条切线相交于任意点"——向外扩张能更早拦截某些切线。极小极大的必要条件是多条不同海岸线同时达到同一最大路程 L（若只有一条岸最坏，还可微调路径压低它）。该问题没有初等闭式解，只能数值求解变分法方程组。
